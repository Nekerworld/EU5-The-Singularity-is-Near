# 천년왕국 대반란 (0.7)

재난 `tsin_millenarian_rebellion`은 태평천국·마흐디 봉기형 대반란을 나라 태그 없이 다룹니다. 정체된 대농업 제국에서 기근·개항 압력·종교 분열이 겹칠 때 시작합니다.

## 시작 조건

- 7시대, 다른 재난·내전 없음, 한 판에 한 번.
- 인구가 1837년 세계 인구의 3% 이상(`tsin_country_world_pop_share`).
- 공장이 하나도 없음(`tsin_has_factory_trigger`가 아님).
- 압박 점수(`tsin_millenarian_pressure`) 2 이상. 1점씩: 병충해 보정치, 개항 압력, 농민 만족도 40% 미만, 안정도 음수, 국교와 다른 종교가 다수인 지점 20곳 이상.

## 흐름

| 단계 | 이벤트 | 내용 |
|---|---|---|
| 시작 | `tsin_millenarian.1` 지상 천국 | 수도가 없는 주 가운데 인구가 많고 만족도가 낮은 8곳의 인구가 반란군(`tsin_millenarian_rebels`, 농민 신분 반란)에 가담. 제국군 토벌(금 −3배, 토벌전 5년) 또는 향신 의용군(15년, 귀족 만족, 최대 세율 −5%) |
| 진행 중 (월 6%) | `.2` 천경, `.3` 외국인 장교의 군대, `.4` 전선 뒤의 기근 | 전쟁세·사면, 용병대 고용(상승군 5년), 곡창 개방 |
| 종료 | `.10` 대반란 이후 | 3년이 지나고 반란군이 모두 사라지면. 대반란의 상처 15년(생산 효율 −5%, 농민 목표 만족도 +5%) |

- 재난 보정치: 반란 가담 문턱 0.05, 월간 반란 성장 0.02, 월간 전쟁 피로 0.1, 농민 목표 만족도 −10%.

## 사용자 확인 필요

- `create_rebel`(category = estate, peasants_estate) 반란군의 실제 규모와 봉기.
- `ordered_province`가 나라 범위에서 소유 주만 고르는지(바닐라 영국 내전과 같은 형식).
- 세계 인구 기준값(`global_var:tsin_world_pop_base`)이 아직 없으면 점유율이 0이 되어 시작하지 않습니다. 1837년 이후 세이브는 세이브 이전 할 일에서 기준값을 채웁니다.
