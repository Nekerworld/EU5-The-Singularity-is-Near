# 노동 조건, 노동 불만, 사회주의 씨앗 (0.7)

7시대 후반의 노동 문제를 바닐라 `laborers` 인구 위에 얹는다. 새 인구 유형이나 신분은 만들지 않는다. 이념 갈등 자체는 8시대 몫이고(`docs/age8_handoff.md`), 7시대에는 불만과 씨앗까지만 둔다.

## 계산 순서 (매년, 연간 집계 순회)

`tsin_aggregate_effects.txt`의 연간 집계가 도시 지점을 한 번 돈다.

1. 공장 일자리 `tsin_location_industrial_jobs`가 0보다 큰 지점만 노동 조건을 계산한다.
2. 지점 변수 `tsin_labor_conditions`에 값을 남긴다. 공장이 사라진 지점은 변수를 지운다.
3. 국가 변수:
   - `tsin_factory_share`: 도시 인구 중 공장 일자리 비율(기존).
   - `tsin_factory_worker_share`: 공장 일자리 ÷ `laborers` 인구.
   - `tsin_labor_conditions`: 공장 일자리로 가중한 평균. 공장이 없으면 0.5.
   - `tsin_socialist_cells`: 세포가 있는 지점 수.
4. `tsin_update_movements_effect`가 노동 불만을 목표값 쪽으로 옮긴다.

## 지점 노동 조건 (0~1)

`tsin_location_labor_conditions` (`script_values/tsin_labor_values.txt`)

| 요소 | 값 |
|---|---|
| 기본 | 0.5 |
| 노동법: 규제 없음 / 공장법 / 노동 보호 | −0.15 / +0.1 / +0.25 |
| 사회 보험 / 구빈법 | +0.1 / +0.05 |
| 과밀(인구 ÷ 수용력이 0.8 초과) | 최대 −0.2 |
| `tsin_model_dwellings`(모범 주택) | +0.1 |
| 최근 사고 `tsin_recent_accident` / 진압 `tsin_strike_suppressed` | 각 −0.1 |
| 평민 평균 만족도 | (만족도 − 0.5) × 0.2 |

## 노동 불만 (0~100)

- 목표값: (1 − 국가 노동 조건) × 100 × min(1, 공장 비중 ÷ 0.1).
  - 불황(`tsin_long_depression`) +10, 결사 자유 정책 −5, 노동조합 승인 −10, 10시간 노동제 −5.
- 매년 목표와의 차이의 25%만큼 움직인다.
- 이벤트와 의제는 `tsin_change_labor_grievance_effect`로 바로 더하거나 뺀다.
- 운동 연결:
  - 노동조합주의: 공장 비중 0.03 이상이면 +1, 불만 ÷ 25.
  - 사회주의: 노동조합주의 50 이상 +2, 불만 50 이상 +1, 세포 수 ÷ 3(최대 +2).

## 사회주의 세포 (1885년 이후)

- 노동 조건 0.35 미만, 공장 일자리 0.5 이상인 지점에 해마다 10% 확률로 생긴다.
- 세포가 있는 지점은 해마다 5% 확률로 같은 시장의 다른 공장 도시(조건 0.5 미만)로 번진다.
- 지점 변수 `tsin_socialist_cell`. 8시대 이념 운동의 출발점으로 넘긴다.

## 특권과 의제

- 평민 특권 `tsin_union_recognition`(노동조합 승인): 노동 운동 기술과 공제 조합 특권이 있어야 한다. 평민 만족도와 권력이 오르고 생산 효율이 2% 내려간다.
- 의제 `pa_tsin_factory_inspection`(공장 감독 강화): 불만 30 이상. 10년 보정치, 불만 −10.
- 의제 `pa_tsin_ten_hour_day`(10시간 노동제): 노동조합 승인과 불만 40 이상. 영구 보정치, 불만 −15.

## 씨앗 이벤트 (풍미 예산 사용)

| 이벤트 | 조건 | 내용 |
|---|---|---|
| `tsin_society.20` 파업 | 노동조합주의 40 | 진압하면 지점에 `tsin_strike_suppressed`(10년) |
| `tsin_society.80` 공장 사고 | 공장 비중 0.03, 조건 0.5 미만 지점 | 지점에 `tsin_recent_accident`(5년). 보상·조사(사고 변수 해제)·책임 전가 |
| `tsin_society.90` 사회주의 독서회 | 세포 1개 이상 | 급습(세포 제거, 진압 변수)·방관·노동조합 흡수(노동조합 승인 필요) |
| `tsin_society.100` 노동절 시위 | 1886년 이후, 불만 50 | 단축 약속·해산(진압 변수, 안정도 하락)·방관 |

## 「모던 타임즈」 이벤트 (`tsin_working_class`, 풍미 예산 사용)

공장이 있는 나라에서 `tsin_working_class_yearly_pulse`(매년 15%)가 고른다. 대부분 한 번만 나오고, 반복 이벤트는 시한 변수로 쉰다.

| 이벤트 | 조건 | 선택지 |
|---|---|---|
| `.10` 공장 시계 | 표준시 채택 | 시계 봉인 / 시간은 돈이다 |
| `.20` 컨베이어 벨트 | 호환 부품 기술 | 속도 올림(`tsin_assembly_line_speedup`, 불만 +5) / 사람은 나사가 아니다(불만 −3) |
| `.30` 급식 기계 | 공작 기계 기술 | 구매(월수입 2배, 70% 실패·30% `tsin_feeding_machine`) / 거절 |
| `.40` 신경 쇠약 | 불만 30, 15년마다 | 공장 의사(`tsin_factory_doctors`) / 정신 병원 |
| `.50` 붉은 깃발 | 사회주의 10, 20년마다 | 주모자 재판(안정도 +, 불만·사회주의 +) / 석방 |
| `.60` 감옥이 더 배부르다 | 장기 불황 진행 중, 10년마다 | 구빈 기금(`tsin_poor_relief`) / 구빈원(`tsin_workhouses`) |
| `.70` 밤의 백화점 | 대량 소비 기술 | 외상 판매(`tsin_consumer_credit`) / 일요일 휴점 |
| `.80` 떠나는 길 | 1870년 이후, 불만 50 | 개척 정착지(불만 −6) / 떠나게 둔다 |

## 사용자 확인 필요

- 노동 조건이 실제 게임에서 0.2~0.8 사이로 퍼지는지(지점 변수는 사회 지도 모드에서 볼 예정).
- 산업국의 불만이 1880년대에 30~60에 이르는지, 너무 빨리 100에 붙지 않는지.
- 세포 확산이 시장 하나를 다 덮지 않는지(관찰자 로그로 세포 수 확인).
- 노동조합 승인 특권이 AI에게 너무 쉽게 또는 너무 늦게 채택되는지.

## 극후반 씨앗 이벤트 (8시대 인계)

이념 갈등은 8시대 몫이므로, 7시대 끝에는 씨앗만 둡니다. 모두 사회 풍미 묶음(`tsin_society_flavor_pulse`, 풍미 예산 사용)에서 나옵니다.

| 이벤트 | 조건 | 내용 |
|---|---|---|
| `tsin_society.110` 국제 노동자 협회 | 1864년 이후, 사회주의 30 이상, 공장 보유, 세계에서 한 번 | 전역 변수 `tsin_first_international_founded`. 금지(사회주의 +3) / 묵인(사회주의 +8, 노동조합 +3) |
| `.120` 무정부주의자의 암살 | 1881년 이후, 노동 불만 60 이상, 20년에 한 번 | 단속법 10년(최대 문해율 −2, 시민 만족 +3%) / 법 유지(안정도 −, 자유주의 +3) |
| `.130` 수도의 코뮌 | 1860년 이후, 평화, 전쟁 피로 5 이상(패전 직후), 사회주의 40 이상, 수도가 도시 이상, 나라당 한 번 | 수도에만 지역 보정치를 붙입니다. 돌파: 피의 주간 10년(불안 +2, 최대 통제 −10%), 노동 불만 +15. 자치: 자치 코뮌 10년(불안 +1, 최대 통제 −5%). 정부 형태는 바뀌지 않습니다. `var:tsin_commune_uprising_happened`가 남습니다 |

`tsin_first_international_founded`와 `tsin_commune_uprising_happened`는 [age8_handoff.md](age8_handoff.md) §1에 적혀 있습니다.
