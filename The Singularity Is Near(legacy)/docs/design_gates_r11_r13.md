# 설계 게이트 R11~R13 (명세만, 완료 아님)

이 문서는 엔진 확인 전까지 **구현 완료로 표시하지 않는** 설계 게이트의 명세입니다. 생성기나 네이티브 망을 바꾸지 않습니다. 세 항목 모두 상태는 `설계 게이트 — 미완료`이며 인게임 확인 전에는 기능 완성이라고 쓰지 않습니다.

## R11 교통 구간 장부 (tools/gen_transport_services.py 거점 유지)

- 목적: 거점(철도역·고속도로 거점 등)은 그대로 두고, 인접 지점과 선정 회랑에 대해서만 구간 장부를 둡니다.
- 구간 ID 명세 항목: 끝점 A·B(거점 ID), 종류(도로/철도/고속), 등급, 소유 국가, 상태(공사/운영), 기준일(연·월).
- 제외: 모든 지점 쌍 생성, 선 렌더링, 부대 경로 변경. 네이티브 공존이 확인되기 전까지 구현하지 않습니다.
- 표시 규칙: 고속도로 거점만으로 장거리망 완성으로 표시하지 않습니다.
- 확인 필요(사용자 확인 필요): 네이티브 도로·철도 네트워크와 장부 구간이 충돌하지 않는지, 인게임 선 표시가 가능한지.

## R12 송전 회랑 캐시 및 기후 자료 구조 (tools/gen_distribution_grid.py 연계)

- E2 (송전 회랑 캐시 시제품 명세만): 선정 회랑의 끝점 거점과 용량 등급만 캐시합니다. 미연결 공장의 시장 구매는 막지 않습니다.
- 기후 자료 구조 (국가 연간 추정용만 정의): 산식 버전, 원자료 연도, 포함 범위, 단위. 공해 0~100 지수를 탄소 톤으로 합산하지 않습니다.
- 보류: 발전 연료별 배출, E3(연료별 배출 집계).
- 확인 필요(사용자 확인 필요): 회랑 캐시가 실제 전력 흐름을 바꾸지 않는지, 원자료 연도 기록 방식이 로드 순서에 영향을 주지 않는지.

## R13 소재 명세 (기존 공해·교통·금융·신문에 연결)

- 소재마다 필요한 항목: ID, 조건(트리거), 선택지, 비용, 종료 조건, 쿨다운.
- 연결 대상: 기존 공해 팝업, 교통 사건, 금융 공지, 신문 기사 큐. 새 시스템을 만들지 않습니다.
- 제외: 800~1200 목표 수치를 맞추기 위한 빈 사건, 연도만으로 열리는 8~12시대 기술, 국제기구 중복 생성.
- 확인 필요(사용자 확인 필요): 소재 목록 확정(사용자 선택 대기), 기존 팝업 연 1회 예산(R05)과의 충돌 정책.

## 완료 처리 기준

| 항목 | 상태 | 완료 조건 |
|---|---|---|
| R11 | 설계 게이트 — 미완료 | 인게임 네이티브 공존 확인 후 장부 구현 |
| R12 | 설계 게이트 — 미완료 | 송전 회랑 캐시와 기후 자료 구조 인게임 확인 |
| R13 | 설계 게이트 — 미완료 | 소재 목록 확정과 연결 대상 확인 |
