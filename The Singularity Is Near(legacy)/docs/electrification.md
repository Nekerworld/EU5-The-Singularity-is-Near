# 전기화 (M5)

## 시대관 발생 시점

`tsin_electrification`(`in_game/common/institution/tsin_age_7_institutions.txt`)은 1870년 이전에는 생기지 않는다. 목표(`docs/balance_targets.md`)는 1875~1885년 발생이다.

| 게임 규칙 | 조건 |
|---|---|
| 무작위 도시 | 1870년 이후, 도시·대도시, 그 지점에 산업자본주의 시대관, 소유국이 `tsin_machine_tools_advance`(공작 기계) 연구 |
| 역사적 고정 | 1875년 이후, 베를린 |
| 그럴듯한 곳 | 1870년 이후, `tsin_electrification_plausible_location`(산업자본주의 시대관, 대학, 문해율 > 50, 건물 레벨 > 200, 혁신 값 > 30), 소유국이 공작 기계 연구 |

게임 규칙 `tsin_electrification_timing`(`main_menu/common/game_rules/tsin_game_rules.txt`):
- 역사적(기본): 위 표 그대로. 1870년 이전에는 생기지 않는다.
- 자유: 날짜 제한을 없앤다. 역사적 고정 규칙에서는 1875년 대신 베를린 소유국이 공작 기계를 연구하면 생긴다.

발생 조건에는 전기화 기술이나 발전소를 쓰지 않는다. 그것들은 전기화 시대관을 받아들여야 열리므로, 조건에 넣으면 영원히 발생하지 않는 순환이 생긴다. 공작 기계는 산업자본주의 기술이라 순환이 없다.

사용자 확인 필요: 관찰 실행에서 발생 연도가 1875~1885년 안에 드는지(`docs/balance_targets.md`). 너무 늦으면 공작 기계 조건을 무작위 도시 규칙에서 먼저 뺀다.

## 기술 8개

`in_game/common/advances/tsin_06_electrification.txt`. 뿌리는 `tsin_electrification_advance`(시대관 수용 필요)다.

| 기술 | 선행 | 효과 |
|---|---|---|
| 실용 전기공학 | 전기화 | 연구 속도 +5%, 구리 산출 +10% |
| 발전기 | 실용 전기공학 | `tsin_power_station` 해금 |
| 중앙 발전소 | 발전기 | 전력 산출 +10%, 수력·석유 발전 방식 해금 |
| 배전망 | 중앙 발전소 | 전력 산출 +15%, 구리 수요 +10% |
| 전동기 | 발전기 | 기계 방직 공장 동력 슬롯에 `tsin_mechanized_electric_drive` 해금 |
| 전기 조명 | 발전기 | `tsin_electric_lighting` 해금 |
| 전신과 전화 | 실용 전기공학 | 내각 효율 +5%, 외교 범위 +25%, 상인 힘 +5% |
| 산업 전동화 | 전동기, 배전망 | 생산 효율 소폭, 비료 공장 `tsin_fertilizer_electrochemical` 해금 |

무료 기술 지급은 없다.

## 발전소와 전력 소비처

`in_game/common/building_types/tsin_power_buildings.txt`. 가격 비율은 다른 공장과 같게 산출 가치 ≈ 투입 비용 × 1.35(정제 방식은 약 1.45)로 맞췄다.

| 방식 | 투입 | 산출 |
|---|---|---|
| 석탄 화력(기본) | 석탄 3, 기관 0.3, 도구 0.2 | 전력 3.78 |
| 수력 | 기관 0.4, 구리 0.3, 도구 0.3 | 전력 2.0 |
| 석유 화력 | 석유 1.5, 기관 0.25, 도구 0.2 | 전력 3.9 |

전력 소비처는 다음 세 가지다. 전력이 모자라면 바닐라 투입 부족 처리로 생산이 줄어든다(`docs/gate_g.md`).

- 기계 방직 공장 전동기 방식: 전력 1.0, 도구 0.15 → 직물 1.67.
- 비료 공장 전기화학 방식: 전력 2.0, 초석 1.5, 명반 1.0 → 비료 6.8.
- 전기 조명망(도시 기반시설, 1단계): 유지비로 전력 0.3, 도구 0.05. 지역 불안 -0.05, 최대 문해율 +5, 이주 매력 +0.05.

수력은 강 조건을 걸지 않았다. 생산 방식 단위로 위치 조건을 걸 수 있는지 확인하지 못해서 산출을 낮게 잡았다.

사용자 확인 필요:
- 발전소와 전기 조명망이 건설 목록에 뜨고 아이콘이 보이는지.
- 잠긴 방식(수력, 석유, 전동기, 전기화학)이 해당 기술 전에는 고를 수 없는지.
- AI가 발전소를 짓는지. 소비처가 없으면 수요가 없어 짓지 않을 수 있다.
