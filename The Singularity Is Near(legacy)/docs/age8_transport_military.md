# 8시대 운송·군사 연결

기준: ac54046 이후 재개 작업. 앞서 구체화된 노급 전함·자동차·항공의 연결만 구현했다. 8시대는 부분 구현이며 새 시대관 3종이나 본격적인 대중정치 체계가 완성된 상태는 아니다.

| 발전 | 선행 | 결과 |
|---|---|---|
| 노급 전함 | 전노급 전함·해군 포술 | 석탄 연료 노급 전함 |
| 중유 연료 주력함 | 노급 전함·내연기관 | 중유 전함 변형 |
| 자동차 운송 | 내연기관 | 자동차 물류 거점 |
| 자동차 보급대 | 자동차 운송·철도 동원 | 기존 육군 이동 개선 |
| 동력 비행 | 내연기관·실용 전기공학 | 수도 항공 시설 |
| 항공 관측 교리 | 동력 비행·참모부 | 기존 지상전 지휘 개선 |

모두 8시대 연구이며 7시대의 산업 자본주의/전기화 수용 조건을 재사용한다. 새 시대관 이름을 임의로 확정하지 않았다. 원본은 `era_8`, 실행 경로는 등록된 매니페스트를 통해 배포한다.

## 유닛과 시설

노급 전함과 중유 전함은 기존 전노급 전함을 직접 상속한다. 엔진에서 수치는 가산되므로 선체/화포/속력의 **증가분**만 선언한다. 각각 증가분은 20/20/0.50, 30/25/1.00이다. 새 함선의 시대는 명시적으로 8시대다. 건조·수리·유지 재화는 별도로 정의하며 중유형은 석유를 지속적으로 소비한다. 기존 함대를 삭제하거나 강제로 교체하는 효과는 없다.

자동차 물류 거점은 엔진·석유·고무·도구를 소비하고 식량 저장/이주 유인을 늘린다. 수도 항공 시설은 수도 도시에서 한 단계만 건설할 수 있고 같은 재화로 운영하여 육군 연락을 지원한다. 별도 항공 유닛·공중전·폭격 엔진을 추가한 것은 아니다. 건물 아이콘과 함선 그림은 기존 산업화 자산을 재사용한다.

## 검사

8시대 이행 포함 관련 회귀 5개 통과. 기술 선행·시대, 가산 상속, 연료 차이, 수도/단계 제한, 원본·런타임·그림 연결을 검사했다. 표준 정적 검사에도 생성기와 그림 비교를 연결했다. 인게임 연구·건설·함선 모집/운용은 전체 구현 이후 검증한다.

8시대 이후 군수 비축·야전 훈련·연료·공군 하이브리드(H1~H4)는 `docs/military_hybrid_h_track.md`, 엔진 실험 질문은 `docs/h0_engine_probes.md`. 모두 사용자 확인 필요.
