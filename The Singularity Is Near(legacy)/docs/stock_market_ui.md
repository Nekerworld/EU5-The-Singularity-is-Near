# 경제 화면 금융·증시 탭

F2 경제의 상위 탭은 수지·금융·시장·관세·교역입니다. 금융은 기존 `credit` 컨트롤러에서 현황·증시·신용 하위 탭을 제공합니다. 현황은 국고·부채·월 차입 지급액·물가와 기존 기업/위기 관측값을 구분해서 표시합니다. 신용은 원본 대출·채권·상환·파산 본문을 그대로 보존합니다. 기존 매개변수 없는 `credit` 링크는 신용을 열고, 예전 `economy / subtab = tsin_stocks` 링크도 금융 선택 표시와 하위 탭을 갖춘 증시로 유지됩니다. 통화·외환·연금은 실제 시스템 구현 전에는 노출하지 않습니다.

상단은 현재 기업·주가 지수와 기존 `tsin_index_h7`→`h0` 여덟 관측값을 연결한 선 그래프입니다. 없는 과거를 0으로 채우지 않습니다. 표본은 통상 분기별이며 거래소 폐쇄 시 간격이 늘어나므로 관측 순서를 표시합니다. 현재 지수는 사건이나 신규 기업으로 마지막 관측값과 달라질 수 있습니다. 아래 기업 목록만 스크롤됩니다.

기업 카드는 공용 카탈로그 20개 유형을 조건에 따라 표시합니다. 상품 아이콘·기업 수·지수·가치 추정치, 본사 이동, 실제 비용과 조건을 검사하는 설립·확장 버튼을 제공합니다. 자유방임일 때 수동 국가 투자는 비활성화되며 한도는 ∞로 표시됩니다. 공용 회계는 분기마다 갱신하며 호버에서 전국 건물을 전수 집계하지 않습니다.

초기 조직 14종, 산업 기업 6종, 경제체제 5종과 위기 조건·역사 근거는 [capital_markets.md](capital_markets.md)에 정리했습니다. 초기 조직은 상업 기반의 근사값이고 산업 기업은 해당 건물 레벨을 사용합니다. 기업 가치가 국고·GDP·현실의 시가총액과 같다는 뜻은 아닙니다.

`tools/gen_stock_market_ui.py`가 경제 진입 경로와 공용 파일을 만들고 `tools/capital_market_ui.py`가 현재 패널을 구성합니다. `--check`로 생성 결과를 비교하며 `--glorp-source <폴더> --compat-output <호환폴더>`로 현재 Glorp 경제 본문·공유 상위 탭과 금융용 credit 본문, 세 파일을 생성·검사합니다. 실제 Glorp 소스가 포함된 호환 GUI는 로컬 전용이고 저장소에 넣지 않습니다. 전체 호환 생성기에도 연결되어 있습니다.

기존 세이브는 탭 진입 시 이미 있는 기업과 통계 캐시를 이행합니다. 주식 관측 이력이나 기업의 과거를 새로 지어내지 않습니다. 게임 재시작 후 탭 진입·수지 복귀·선 표시·스크롤·본사 이동·비용 및 정책 조건은 인게임 확인이 필요합니다.
