# 변경 이력

맨 위 항목의 버전은 `.metadata/metadata.json`의 `version`과 같아야 한다(`tools/build_release.py`가 검사). 버전 규칙은 `docs/release.md`.

## 0.7.0 (개발 중) — 산업 사회로의 진입

게임 안 시험 전 빌드다. 모든 기능이 **사용자 확인 필요** 상태다. 세이브 이전 버전(`tsin_version`)은 3이다. 0.7 작업은 이 한 항목에 모았다.

### 상시 로그와 로그 읽기 도구
- 플레이어 나라가 매달 점검 19종(`chk`)과 숫자 스냅샷(`snap`)을 `debug.log`에 자동으로 남긴다. 게임 규칙은 필요 없다. 조사 버튼, 국가 비교, 세계 기업 조사, 기업 상장은 실행할 때 훅 줄(`hook`)을 남긴다.
- 기존 `TSIN_OBS`/`TSIN_ECON` 줄이 비어 있던 원인(`debug_log`에서 ROOT가 null)을 확인하고, 새 로그는 고정 문구와 전역 변수 읽기로 나눴다. 전역 변수 읽기가 로그에서 되는지는 **사용자 확인 필요**.
- `tools/read_log.py`: 로그를 PASS/WARN/FAIL/미검증 판정, 기능 사용 횟수, 스냅샷 표, 이 모드의 `error.log` 오류로 정리. `docs/mod_log.md`.

### 금융계약 연속성과 README 갱신
- 해외 신용을 숫자 계약 ID와 영속 맵으로 다중화. 국내 기업 대출·회사채도 개별 금리·만기·지급일·연체를 보존하며 중복 이자를 차단.
- 합병 유형과 무관한 국가 국고·채무 및 민간 자산/부채 승계. 준비/확정/복구 일지, 네이티브 Loan 당사자 변경, 연쇄/중복/취소/누락 콜백 처리.
- 구형 회사채 만료 변수가 유실되면 날짜를 조작하지 않고 원금을 유지해 확인 대상으로 표시. 채무자가 확인한 날짜의 명시적 복원 제공.

### 알려진 제한
- 그림은 바닐라 그림을 다시 칠한 임시 그림이다.
- 다른 모드와 같은 바닐라 객체를 바꾸면 이 모드 쪽이 적용된다(`docs/compat.md`).
- 모드를 켠 세이브에서 모드를 끄면 세이브를 쓸 수 없다(`docs/release.md`).
