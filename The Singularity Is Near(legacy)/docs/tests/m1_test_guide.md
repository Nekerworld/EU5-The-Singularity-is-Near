# M1 시험 절차서 (관문 A~D, H, I, 세이브 재로드)

이 문서의 시험은 모두 **사용자 확인 필요**다. 정적 검사(`python tools/validate.py`)는 통과했지만 게임을 실행하지 않았다.

## 준비

1. 런처 재생 목록에 **The Singularity is Near**만 켠다. 첫 시험에서는 다른 모드를 끈다.
2. 기존 로그를 정리하려면 게임을 한 번 껐다 켠다. 로그는 실행할 때마다 새로 쓴다.
3. 시험이 끝날 때마다 모드 폴더에서 `python tools/scan_logs.py`를 실행하고 출력을 결과란에 붙인다.

## 시험 0 — 메인 메뉴 로드

| 단계 | 기대 결과 |
|---|---|
| 게임을 켜고 메인 메뉴까지 간다 | 오류 창 없이 메뉴 표시 |
| `python tools/scan_logs.py` | `error.log`에 `tsin_`, `age_7_industrialization` 관련 줄이 없거나, 있으면 그 줄을 보고 |

## 관문 A·B — 1837년 시대 전환과 종료 미발생

| 단계 | 기대 결과 |
|---|---|
| 새 게임(아무 국가) → 콘솔 `debug_mode` → `change_date 1836` | 날짜 이동 |
| 1837년 1월 1일을 넘길 때까지 진행 | 바닐라 `ages_of_eu.1`과 이 모드의 `tsin_system.2` "산업 시대" 안내가 뜸 |
| 시대 화면을 연다 | 제7시대 "산업 시대"가 VII 아이콘과 함께 표시됨 |
| 1837년 이후 몇 달 더 진행 | 게임 종료 화면이 뜨지 않음 (관문 B) |
| 대안: `change_age age_7_industrialization` | 날짜 이동 없이 시대만 바뀌는지 확인 |

## 관문 C — 제도 등장, 확산, 수용

| 단계 | 기대 결과 |
|---|---|
| 1840년 이후까지 진행하거나 `spawn_institution tsin_industrial_capitalism manchester` | 제도 화면에 "산업자본주의" 등장 |
| 다음 해 1월까지 진행 | `tsin_system.10` 알림이 한 번만 뜸 |
| `spawn_institution tsin_mass_society paris`, `spawn_institution tsin_electrification berlin` | 각각 등장, 알림 `tsin_system.11`, `.12` |
| 확산 진행을 몇 년 관찰 | 주변 지점으로 진척도가 늘어남 |
| 진척도가 충분해진 뒤 수용 | 수용 버튼이 동작 |

## 관문 D — 기술 잠금과 개방

| 단계 | 기대 결과 |
|---|---|
| 제7시대 진입 직후 기술 화면 | "증기의 시대"는 연구 가능, 제도 기술 3개는 잠김 |
| 산업자본주의 수용 전 | "산업자본주의" 기술 잠김 |

| 대중사회, 전기화도 같은 방식으로 확인 | 동일 |

## 관문 H — 새 지도 모드 파일 로드

| 단계 | 기대 결과 |
|---|---|
| 지도 모드 메뉴의 "인구 통계(demography)" 분류를 연다 | "산업 시대 제도" 항목이 보임 |
| 선택한다 | 제도가 없는 지점은 낮은 색, 제도가 있는 지점은 단계별 색 |
| 콘솔 `mapmode_report` | 이 지도 모드에 툴팁 누락 경고가 없음 |
| 바닐라 "제도(institution)" 지도 모드 | 새 제도가 선택 목록에 보이고 확산이 칠해짐 |

메뉴에 보이지 않으면 엔진이 새 지도 모드 파일을 읽지 않는 것이다. 이 경우 바닐라 `map_modes.txt` 전체를 덮어써야 하므로 결과를 알려 주면 대안을 정리한다.

## 관문 I — 개별 객체 덮어쓰기

| 단계 | 기대 결과 |
|---|---|
| 제7시대에 다른 나라 지점을 대상으로 전쟁 선포 화면 | `cb_imperialism`(제국주의), `cb_nationalist`(민족주의) 전쟁명분이 제6시대처럼 나타남 |
| 기술 화면, 툴팁 | `current_age_at_least_7_tt` 같은 키 문자열이 그대로 보이지 않음 |
| `error.log` | `TRY_REPLACE` 관련 "object not found" 또는 중복 정의 경고가 없음 |

## 세이브 재로드

| 단계 | 기대 결과 |
|---|---|
| 제7시대 진입 후 저장 → 메인 메뉴 → 불러오기 | 정상 로드 |
| 다음 해 1월까지 진행 | 제도 알림이 다시 뜨지 않음 (중복 없음) |
| 모드 없이 만든 1836년 말 세이브를 모드를 켜고 불러와 1837년을 넘김 | 시대 전환이 일어나고, 첫 해 1월에 `tsin_system.1`이 조용히 한 번 실행됨 |
| 콘솔 `debug_mode` 후 결단 목록 | `[TSIN 디버그]` 결단 3개가 보임. `debug_mode`를 끄면 사라짐 |
