# M2 시험 절차서 (관문 E~F, 산업화 지도 모드, 경제 이벤트)

이 문서의 시험은 모두 **사용자 확인 필요**다. 정적 검사(`python tools/validate.py`)는 통과했지만 게임을 실행하지 않았다. M1 시험(`m1_test_guide.md`)의 시험 0과 관문 A를 먼저 통과해야 한다.

## 준비

1. M1과 같이 이 모드만 켜고 새 게임을 시작한다. 공장이 있는 산업국(예: 영국, 프랑스)을 고르면 관찰이 쉽다. 국가 태그는 시험 편의일 뿐 조건이 아니다.
2. 콘솔 `debug_mode` → `change_age age_7_industrialization`(또는 1837년까지 진행).
3. 시험이 끝날 때마다 `python tools/scan_logs.py`를 실행해 결과란에 붙인다.

개발용 결단(`debug_mode`에서만 보임):

| 결단 | 효과 |
|---|---|
| `[TSIN 디버그] 시험 공장 건설` | 수도에 기계 공장과 직물 방직소를 즉시 건설 |
| `[TSIN 디버그] 방직소 기계화` | 수도에 기계화 방직 공장을 즉시 건설(방직소 개축 경로 확인) |
| `[TSIN 디버그] 기관 품귀` / `기관 과잉` | 수도 시장의 기관 공급을 크게 줄이거나 늘림 |
| `[TSIN 디버그] 경제 이벤트 1` / `2` | `tsin_economy.10`·`.20` / `.30`·`.40`을 띄움 |

## 시험 0 — 데이터 로드

| 단계 | 기대 결과 |
|---|---|
| 메인 메뉴까지 로드 후 `scan_logs.py` | `tsin_engines`, `tsin_machine_works`, `tsin_mechanized_textile_mill`, `goods_tsin_engines` 관련 오류 없음 |
| 시장 화면의 상품 목록 | "기관"이 아이콘과 함께 보임 |
| 기술 화면(제7시대) | "기계 공장", "강철 틀 기관", "기계화 방직 공장" 기술이 "증기의 시대" 뒤에 이어짐 |

## 관문 E — 다중 슬롯과 대체 생산 방식

| 단계 | 기대 결과 |
|---|---|
| "기계 공장" 기술 연구 후 수도에 기계 공장 건설(또는 디버그 결단) | 건설 가능, 건설 수요에 강철·기관이 포함 |
| 건물 창을 연다 | 생산 방식 슬롯이 2개("틀 방식", "부속 방식") 보임 |
| 틀 슬롯 | "주철 틀" 선택 가능, "강철 틀"은 잠김 표시 |
| "강철 틀 기관" 기술 연구 후 | "강철 틀" 선택 가능 |
| 부속 슬롯에서 "구리 부속" ↔ "유리 계기" 전환 | 투입재 목록이 바뀌고, 산출 기관 수량이 두 슬롯 합으로 표시 |
| 슬롯을 바꾼 뒤 한두 달 진행 | 바꾼 방식이 유지되고 오류 없음 |

## 관문 E 확장 — 자동화 단계(개축)

| 단계 | 기대 결과 |
|---|---|
| 직물 방직소가 있는 지점에서 "기계화 방직 공장" 기술 연구 | 건설 메뉴에서 기계화 방직 공장이 "직물 방직소에서 개축"으로 표시 |
| 개축 실행(또는 디버그 결단) | 방직소가 사라지고 같은 레벨의 기계화 방직 공장이 생김. 정착 진행도 일부 승계 |
| 건물 창 | 원료 슬롯(목화·양모·섬유 작물)과 동력 슬롯(증기·수력) |
| 고용 | 레벨당 고용 인원이 방직소보다 적음(0.25 → 0.15) |
| 개축 후 직물 방직소를 새로 지을 수 있는가 | 바닐라 `obsolete` 동작대로 막히는지 기록 |

## 관문 F — 수직 순환과 가격 반응

`docs/economy_chain.md`의 순환(철·석탄 → 강철 → 기관 → 기계화 방직 → 직물 → 인구 수요)을 관찰한다.

| 관찰 항목 | 방법 | 기대 결과 |
|---|---|---|
| 기관 가격 | 시장 화면 | 기본가 6 근처에서 출발 |
| 기관 품귀 | `기관 품귀` 결단 → 1~3개월 진행 | 기관 가격 상승, 기계화 방직 공장의 증기 동력 방식 수익 하락 |
| 기관 과잉 | `기관 과잉` 결단 → 1~3개월 진행 | 기관 가격 하락, 기계 공장 수익 하락 |
| 수력 ↔ 증기 | 품귀 상태에서 동력 슬롯을 수력으로 바꿈 | 수익이 회복되는지(교환 관계 확인) |
| 함선 수요 | 제7시대 함선 건조 시작 | 시장 수요 내역에 기관이 함선 건조로 잡힘 |
| 직물 수요 | "대중사회" 기술 연구 전후 | 직물 인구 수요가 약 10% 늘어남 |
| 고용 | 기계 공장·기계화 방직 공장 건물 창 | 노동자 고용, 수익, 정착 진행도가 정상 표시 |
| 산업 장려 | 도시 권리·산업 장려 화면 | "기계 공업"이 제7시대 이후에만 보이고, 기관 생산 보정치가 생김 |

결과는 수치로 남긴다: 기관 가격(전/후), 건물 수익(전/후), 고용 인원.

## 산업화 지도 모드

| 단계 | 기대 결과 |
|---|---|
| 지도 모드 메뉴 "경제(economy)" 분류 | "산업화" 항목이 아이콘과 함께 보임 |
| 선택 | 공장 없는 소유 지점은 최소 색, 공장 있는 지점은 낮은→높은 색 그라데이션 |
| 공장이 있는 지점에 마우스 | 툴팁 "공장 일자리는 인구의 N%입니다 (레벨 M)" — N과 M이 숫자로 보임 |
| 공장 1레벨 지점의 N을 건물 창 고용 인원 ÷ 지점 인구와 비교 | 대략 일치(단위 가정 검증) |
| 디버그 결단으로 공장 추가 후 다음 달 | 색이 갱신됨 |
| 콘솔 `mapmode_report` | 툴팁·범례 누락 경고 없음 |

툴팁의 N, M이 0으로만 나오거나 지도가 전부 최소 색이면 `location_building_level(...)` 함수형 값이 스크립트 값의 `add`에서 동작하지 않는 것이다. 이 경우 결과를 알려 주면 트리거 기반 계산으로 바꾼다.

## 경제 이벤트

| 단계 | 기대 결과 |
|---|---|
| `경제 이벤트 1` 결단 | 공장 사고(지점 이름 표시), 원료 부족 이벤트가 뜸 |
| 각 선택지 툴팁 | 금, 계층 만족도, 지점·국가 보정치가 표시되고 키 문자열이 그대로 보이지 않음 |
| `경제 이벤트 2` 결단 | 숙련공 부족, 공장 확장 제안 이벤트가 뜸(숙련공 부족은 공장 지점 3곳 이상 필요) |
| 10년 이상 자연 진행 | 국가당 `tsin_` 플레이버 이벤트가 1년에 3개를 넘지 않음 |
| 관찰자 모드 몇 년 | AI가 금이 부족할 때 금을 쓰는 선택지를 고르지 않음 |
