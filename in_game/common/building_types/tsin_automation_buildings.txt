# Age VII automation tier: upgrades the six vanilla mills in place (obsolete), one good each.
# Production methods are tech tiers only: steam power (base, output 6) -> electric motor (output 7,
# unlocked by tsin_electric_motor_advance). Raw inputs keep the vanilla mill recipe in proportion and are
# scaled so that output value = input value * 1.35 (mills_profit_margin), as in vanilla mills.
# Prices: iron 3, coal 2, tools 3, sand 0.5, stone 1, alum 3, lumber 1.5, dyes 4, lead 2, paper 2, cloth 3,
# glass 3, furniture 3, books 3, fine_cloth 6, tsin_engines 6, tsin_electricity 3.
