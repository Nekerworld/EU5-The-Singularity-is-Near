## 준비
1. 같은 PC, 같은 해상도·그래픽 설정, 다른 프로그램을 최소화한 상태에서 측정한다.
2. Steam 실행 옵션에 `-debug_mode`를 추가한다. 콘솔(`` ` `` 키)에서 `help`로 명령 이름을 확인한다.
3. 플레이셋은 두 가지를 준비한다.
   - **A (기준):** 바닐라 + 평소 쓰는 모드(이 모드 제외)
   - **B (시험):** A + The Singularity is Near
4. 시험 세이브: 1827년 1월 1일 근처의 같은 세이브 1개. 엔딩 직전 세이브가 있으면 그것을 쓴다.

## 측정 방법
- 관찰 모드(콘솔 `observe`)로 전환하고 최고 속도로 진행한다.

- 같은 구간을 2회 측정해 평균을 쓴다. 두 값의 차이가 10%를 넘으면 3회째를 잰다.

## 판정
- `docs/balance_targets.md` 7절의 목표와 비교한다.
- 목표를 넘으면 의심 순서대로 확인한다.

## M6 점검 (AI·현지화·성능)

### 정적 점검 `python tools/audit.py`

배포 전에 `tools/validate.py`와 함께 돌린다. 오류가 0이어야 한다.

| 항목 | 기준 |
|---|---|
| AI | 무언가를 해금하는(`unlock_*`) 기술에는 `ai_weight`가 있다. 바닐라도 기술의 약 5%에만 가중치를 붙이므로 나머지는 엔진 기본값에 맡긴다. 결단에는 `ai_will_do`가 있다. 선택지가 둘 이상 보이는 이벤트는 모든 선택지에 `ai_chance`가 있다(선택지마다 `trigger`가 있어 하나만 보이는 이벤트는 제외). |
| 현지화 | 영어 파일마다 같은 키를 가진 한국어 파일이 있다. 데이터 함수(`[Show...(...)]`)와 `$참조$`가 두 언어에서 같다. 영어와 똑같은 한국어 문장은 번역 누락으로 본다. |
| 성능 | 나라별 맥동(연간·월간 on_action)과 힌트 안에서 전 세계를 도는 조건(`any_country`, `every_location` 등)을 찾는다. |

2026-11-14 결과: 오류 0, 경고 1.
- 해금 기술 18개에 `ai_weight = { add = 25 }`를 더했다(기존 해금 기술과 같은 값). `tsin_hunger.10`의 첫 선택지에 `ai_chance`를 더했다.
- 경고 `tsin_economy.70`(설계도 도용): 조건 안의 `any_country`는 값싼 국가 조건 세 개(예산, 산업자본주의 수용, 공작 기계 미연구)를 통과한 나라에서만 돌고 첫 일치에서 멈춘다. 그대로 둔다.
- 상황(`situations/`)의 `every_country`는 상황마다 한 달에 한 번 세계 단위로 돈다(나라 수에 비례). 나라별 맥동이 아니므로 제곱 비용이 생기지 않는다.
- `tsin_flavor.10`은 기술 수 상위 8국 판정(`tsin_world_exhibition_leader_trigger`, 전 세계 순회)을 쓰지만, 예산·날짜·완료 여부·공장 없음 조건 뒤에 두어 공장이 없는 나라에서만 돈다.

### 0.7 Modern Times 단계 정적 점검 (2026-11-14)

`python tools/audit.py`: 오류 0, 경고 1(위 `tsin_economy.70`, 그대로). 0.7에서 늘어난 비용:
- 이벤트: 노동 계급 `.20`~`.80`, 경제 `.90`~`.130`, 사회 `.130`~`.170`, 발명 `.80`~`.100`은 모두 기존 맥동의 `random_events` 가중치로 들어가고 이벤트 예산 조건을 먼저 본다. 조건 안에 전 세계 순회가 없다.
- 지도 모드 8종: 위치 값(`tsin_map_values.txt`)은 자기 위치·시장·소유국 변수만 읽고 순회하지 않는다. 세계 최고 1인당 GDP는 위치마다 세지 않고 연 1회 `tsin_update_world_gdp_effect`가 전역 변수로 저장한다(전역 타이머 360일, 나라 수만큼 1회 순회).
- 관찰 값 5개(`gp_food`, `bills`, `gp_index`, `gp_gdp_pc`, `gdp_pc_max`): 게임 규칙 '관찰 측정 기록'이 켜졌을 때 1년에 한 번만 계산한다.

실행 측정은 아래 표로 한다. 지도 모드 비교에는 0.7 지도 모드 8종(자동화, 공업 입지, 기반 시설, 노동 조건, 주거, 1인당 GDP, 기업, 농업)도 넣는다.
