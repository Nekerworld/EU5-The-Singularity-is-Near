# 성능 기준선 측정 절차

에이전트는 게임을 실행할 수 없으므로 측정은 사용자가 한다. 결과는 아래 표에 기록한다.

## 준비
1. 같은 PC, 같은 해상도·그래픽 설정, 다른 프로그램을 최소화한 상태에서 측정한다.
2. Steam 실행 옵션에 `-debug_mode`를 추가한다. 콘솔(`` ` `` 키)에서 `help`로 명령 이름을 확인한다.
3. 플레이셋은 두 가지를 준비한다.
   - **A (기준):** 바닐라 + 평소 쓰는 모드(이 모드 제외)
   - **B (시험):** A + The Singularity is Near
4. 시험 세이브: 1827년 1월 1일 근처의 같은 세이브 1개. 엔딩 직전 세이브가 있으면 그것을 쓴다.

## 측정 방법
- 관찰 모드(콘솔 `observe`)로 전환하고 최고 속도로 진행한다.
- 시작 날짜와 끝 날짜에서 실제 시간을 스톱워치로 잰다. 연도당 초 단위로 기록한다.
- 같은 구간을 2회 측정해 평균을 쓴다. 두 값의 차이가 10%를 넘으면 3회째를 잰다.

| 구간 | 플레이셋 | 1회(초) | 2회(초) | 평균(초/년) | 비고 |
|---|---|---|---|---|---|
| 1827~1836 | A | | | | 바닐라 기준 |
| 1827~1836 | B | | | | 모드 비용(제7시대 전) |
| 1837~1847 | B | | | | 제7시대 초기 |
| 1890~1900 | B | | | | 콘텐츠 최대 |
| 1900~1910 | B | | | | 콘텐츠 이후 |

## 판정
- `docs/balance_targets.md` 7절의 목표와 비교한다.
- 목표를 넘으면 의심 순서대로 확인한다.
  1. 지도 모드 갱신 주기
  2. 월간 on_action의 전 세계 순회
  3. 이벤트 `trigger`의 `any_*` 순회
  4. 생성 패치 객체 수

## 기록
- 날짜, 게임 버전, 모드 버전(`.metadata/metadata.json`의 `version`), 활성 모드 수를 함께 적는다.
- 결과 파일: `docs/results/perf_<날짜>.md`
