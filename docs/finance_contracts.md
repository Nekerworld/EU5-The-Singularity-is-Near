# 금융계약 원장과 합병 승계

사용자 확정 원칙: 합병 유형과 관계없이 국가 자산·국가 채무를 승계하고 은행·기업·연금·보험의 자산과 부채를 함께 보존한다. 몰수·채무 불인정은 별도 정책으로 분리하며 이 구현에서 자동 적용하지 않는다.

## 계약을 합산하지 않는 원장

원본은 `tools/finance_contracts.py`, 국내 대출/회사채 확장은 `tools/private_contracts.py`다. 전역 영속 변수 맵에 단조 증가하는 숫자 ID를 키로 계약 행을 저장하고 활성 ID 목록을 관리한다. 가짜 국가·캐릭터·국제기구와 고정 슬롯 배열을 만들지 않는다. 국가 변수는 UI용 합계이며 원금의 권위는 개별 행에 있다.

각 행은 채권자·채무자, 원금 통화·환산율, 통화 원금, 발행 금리, 만기 월, 다음 지급 월, 지급 간격, 연체 횟수, 계약 종류를 보존한다. 월은 `연도×12+월`로 저장하며 합병 때 만기와 다음 지급일을 다시 시작하지 않는다. 개인별 법인·공장 소유권은 여전히 국가 단위의 합산 경제 모형이다.

| 종류 | 금리·만기·지급 |
|---|---|
| 해외 기업 신용 | 신규 12개월 또는 60개월 계약, 발행 당시 신용 금리 고정, 60개월은 2%p 가산(최대 20%), 3개월마다 이자, 만기 이후 가용 현금으로 상환 |
| 국내 은행→기업 신용 | 발행 당시 금리, 정해진 만기 없이 월 이자와 수동/AI 원금 상환 |
| 민간 회사채 | 연 4%, 36개월 만기, 실제 시민 계층 자금으로 인수, 월 이자와 만기 상환 |

계약 체결과 상환은 실제 은행·기업·시민 현금을 반대로 움직인다. 현금을 넘는 지급, 주가/GDP에서의 현금 생성, 기존 국가 대출에 대한 추가 이자는 없다. 새로운 정책 금리는 이미 발행한 계약을 다시 가격 매기지 않고 신규 계약에 적용한다. 기존 국내 신용은 이행 당시 금리를 보존한다.

해외 신용은 국가당 한 건 제한을 제거하고 12개월 발행 간격을 적용한다. 합병 뒤에도 기존 여러 계약을 하나로 합치지 않는다. 기존 해외 계약은 현금을 다시 지급하지 않고 원금·연체 횟수와 남은 분기 수를 이행하며, 옛 연 4% 조건을 유지한다. 옛 모형은 실제 발행일 대신 분기 처리 횟수만 저장했으므로 그 남은 횟수를 월 일정으로 이어받는다.

평가절하는 해당 통화 채권의 기준 두캇 가치를 바꾼다. 10:1 화폐개혁은 관련 원금과 환산을 함께 나누어 실질 가치를 유지한다. 통화 발행국이 합병되면 준비 단계의 환산율을 고정하여 기존 통화 표시 채권을 보존한다. 합병국의 통화로 원금을 임의 재표시하지 않는다. 당사자 둘이 같은 국가가 되어도 은행 계정과 기업 계정 사이의 청구를 자동 면제하지 않는다.

## 합병 준비·확정·복구

생성기는 `tools/finance_succession.py`다. 바닐라 `_hardcoded.txt`에 정의된 공용 `on_annex`와 `on_annexed`를 확장하며 군사·외교·내전 등 합병 유형에 따라 면제하는 조건은 두지 않는다.

1. 준비: 당사자를 확인하고 기존 TSIN 계약을 이행한다. 국고·환산율·은행/기업 현금·준비금·기금·예금·인출 요구·유동성 채무·지분 수량·누적 손실과 운영 표식을 별도 일지에 저장한다. 국고는 준비 현금으로 보관해 엔진 이전과 중복되지 않게 한다.
2. 바닐라 국가 대출: 원래 Loan 객체와 변경 전 당사자를 기록하고 채무자·국가 채권자만 합병국으로 바꾼다. 원금·금리·만기를 다시 발행하거나 이자를 중복 부과하지 않는다. 같은 Loan이 중첩된 준비에 등장하면 각각 다른 일지 ID를 사용한다.
3. 확정: 피합병국의 소멸을 확인한 뒤 준비 국고와 TSIN 자산·부채를 합병국에 함께 인도한다. 계약의 당사자만 재연결하고 원금·금리·만기·연체·지급 주기를 유지한다. 소멸국의 이전된 TSIN 잔액은 0으로 정리해 부활 시 복제되지 않게 한다.
4. 복구: 합병이 확정되지 않고 국가가 살아 있으면 준비 국고와 변경한 Loan 당사자를 돌려준다. 완료 콜백이 누락되면 다음 월 점검에서 국가 생존 여부에 따라 복구 또는 확정한다. 중복 콜백은 한 번만 적용한다. 후속 합병에는 미완료 일지의 수취인을 이어준다.

음수 국고·순자산 부족·예금과 미지급 인출·유동성 채무를 임의로 없애지 않는다. 청산 중인 은행은 자기 예금의 인출 요구만 넘기며 합병국 전체 은행을 강제로 폐쇄하지 않는다. 준비금·기금은 국고와 구분한 실제 현금 장부로 보존한다. 지분 수량과 공적 보유 단위도 보존하지만 회사별 공정 가치 평가를 하는 모형은 아니다.

**원자성의 범위:** EU5의 국가 합병 전체를 취소하는 ACID API는 확인되지 않았다. 이 코드는 자체 금융 준비·확정·복구와 중복 실행 방지를 제공한다. 영토·외교·군대·타 모드의 효과와 엔진 내부 실패까지 한꺼번에 되돌리는 트랜잭션이라고 주장하지 않는다. 특히 바닐라 Loan 객체의 실제 합병 동작은 최종 인게임 검증 대상이다.

## 구형 회사채의 만기

옛 회사채는 만기 날짜가 아니라 만료 변수 `tsin_bond_maturity`만 저장했다. 이행 시 그 원래 타이머를 계속 확인하며 새 36개월 타이머를 만들지 않는다. 합병 과정에서 엔진이 타이머를 지우면 만기를 추측하지 않고 원금·금리를 유지한 채 날짜 미확인 상태로 남긴다. 은행 화면에 미확인 수와 확인 대상 계약번호를 표시한다. 이 상태에서는 자동 원금 만기 상환을 강제하지 않으며 이자와 청구 기록은 유지한다.

원래 날짜를 별도 기록에서 확인한 경우 다음 **스크립트 효과 형식**으로만 명시적으로 복원할 수 있다. 자동 복원 규칙이나 새로운 콘솔 명령의 이름은 아니다.

```text
tsin_contract_restore_legacy_maturity_effect = { ID = 17 YEAR = 1852 MONTH = 7 }
```

현재 실행 국가가 해당 계약의 채무자이고 미확인 구형 회사채일 때만 적용한다. 날짜 범위를 검사하며 원금·금리·현금은 바꾸지 않는다. 신규 회사채는 처음부터 숫자 만기 월을 저장하므로 이 제한이 없다.

## 검증과 성능

계약 원장 실행 회귀 8개와 합병/복구 실행 회귀 12개를 추가했다. 생성된 스크립트를 해석해 여러 금리·만기·상대국, 이행 반복, 현금 보존, 기존 만기, 상각, 네이티브 Loan 주체 변경, 중첩/중복/취소/누락 훅, 음수 국고, 환산율 소멸, 은행 청산 범위와 명시적 날짜 복원을 검사한다. 엔진 자체를 실행한 시험은 아니다.

월간 공용 점검은 달력 월에 한 번만 수행한다. 국가 합계 초기화와 활성 계약 순회가 기본이며 국가마다 전 세계 계약을 중첩 순회하지 않는다. UI 호버·렌더링은 계약을 결제하지 않는다. 수동 거래와 합병은 필요한 합계 재집계를 추가 수행한다. 실제 대규모 진행의 성능과 원본 타이머 보존은 인게임 검증이 남아 있다.
