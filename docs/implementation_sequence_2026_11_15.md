# 미래 개발계획 실행 순서 — 2026-11-15

기준: `68e8158`. 사용자 요청에 따라 계획을 작성한 뒤 논리 단위별 구현·검증·로컬 커밋으로 진행한다. 푸시는 하지 않는다. 기존 미커밋 ‘전선 자동전투 무기한 보류’ 표시는 보존하며 이 연구는 이번 개발에서 제외한다.

## 공통 규칙

- 실행 상태는 계획/구현 중/정적 검증/인게임 대기로 구분한다. 정적 검사 통과를 인게임 성공으로 기록하지 않는다.
- 원본은 생성기·데이터·등록된 `era_7`에서 관리한다. 전역 기능을 시대 전용 경로로 옮기지 않는다.
- 설치된 HEX 0.3.5와 기존 통일·금융·콜레라 체계를 중복 실행하지 않는다. 파괴적인 영토 조정은 진단·보호 조건 검증부터 진행한다.
- 새로운 엔진 기능이 필요한 항목은 기존 사용례·구문을 먼저 확인한다. 지표가 없으면 실제 관측으로 위장하지 않는다.
- 매 단계 관련 생성기 검사·회귀 검사·정적 검사를 통과시킨 뒤 커밋한다. 저위험 문서 변경에 별도 게임 테스트를 만들지는 않는다.
