# 금융계약 연속성 구현 계획

사용자 결정: 합병 유형과 관계없이 국가 자산/채무 승계, 민간 자산과 부채의 동시 보존, 해외 다중 계약. 몰수·채무 불인정은 구현하지 않는다. 개별 계약의 금리와 만기 정보를 합산으로 대체하지 않는다.

1. 전역 영속 변수 맵과 활성 ID 목록으로 계약 원장을 생성한다. 국가를 계약 ID로 사용하거나 가짜 국가·캐릭터를 생성하지 않는다. 계약별 당사자·통화 원금·환산·금리·만기·지급 주기·연체를 저장한다. 기존 계약의 이행은 현금을 추가 지급하지 않는다.
2. 해외 신용부터 다중화하고, 합병으로 금리/만기가 섞이지 않도록 TSIN 국내 은행 대출과 회사채도 계약별 기록으로 옮긴다. 기존 국가 대출은 엔진 Loan 객체를 유지한다. 원금·이자 지급은 반드시 기존 현금에서 차감하며 평가손익은 현금을 생성하지 않는다.
3. 공용 on_annex/on_annexed 훅을 사용한다. 합병 전 준비 일지에 국고·TSIN 자산/채무와 네이티브 계약 원래 주체를 기록한다. 국고는 별도 준비 현금으로 보관해 엔진의 국고 이전과 중복되지 않게 하고, Loan 주체만 변경하여 삭제를 피한다. TSIN 계정 합산·계약 재연결·국고 인도는 합병 확인 후 수행한다. 취소되어 피합병국이 살아 있으면 준비 일지를 돌려준다. 반복 콜백은 한 번만 적용한다.
4. EU5 엔진의 국가 합병 전체에 대한 ACID 롤백은 확인되지 않았다. 자체 준비/완료/복구 일지와 멱등성을 구현하며 영토·외교·타 모드 효과까지 되돌리는 원자적 합병이라고 주장하지 않는다.
5. 기존 회사채는 만기가 숫자 날짜가 아닌 만료 변수로 저장되어 있다. 신규 계약부터 절대 월 만기를 기록하고 기존 채권의 원래 타이머를 보존하는 이행 경로를 별도 검증한다. 날짜를 임의로 36개월 연장하거나 즉시 만기 처리하지 않는다.
6. 테스트: 서로 다른 금리/만기, 복수 상대국, 채권자/채무자/양쪽 합병, 연쇄·중복 콜백, 실패 준비 복구, 음수 국고·미지급 예금·연금/보험·소유 지분, 실제 현금·원금·자산/부채의 보존, 기존 세이브 이행, 평가절하·개혁·상각. 이후 기본/Glorp 연결과 문서/README를 갱신하고 작업별 로컬 커밋한다. 인게임 테스트·푸시·백업은 하지 않는다.

## 구현 결과

계약별 전역 맵·활성 ID, 해외/국내 기업 신용·회사채 이행, 금리/만기 분리, 공용 합병 훅·국고 준비·대출 당사자 승계·계정 인도·중복/취소/누락 콜백 복구를 구현했다. 실행 회귀 20개를 추가했고 전체 119개 검사를 기준으로 마감한다. 구형 만기 변수가 유실되면 원금을 보존하고 확인 대상으로 표시하며 명시적 날짜 복원 효과를 제공한다. 실물 엔진 검증은 전체 구현 이후 진행한다. 상세 범위와 제한은 [finance_contracts.md](finance_contracts.md)를 따른다.
