# 콜레라 재앙 화면 (2026-11-15)

국가 재앙 tsin_cholera에는 전용 패널이 없어 빈 화면이 열렸다. 바닐라 disaster_panel 형식의 in_game/gui/panels/disaster/tsin_cholera.gui를 추가했다. 기본 재앙 화면의 월간 효과, 행동 목록, 종료 요건을 유지하며 국가 변수의 종식 진행도와 도시 발병 횟수, 대책 안내를 표시한다. 공중보건 운동은 기존 내각 행동으로 실시하며 새로운 무료 행동 버튼은 추가하지 않았다. 재앙의 발생·피해·종료 로직은 변경하지 않았다.

인게임 확인: 진행 중인 재앙 화면이 열리는지, 진행도와 발병 횟수가 숫자로 나오는지, 한 달 뒤 갱신되는지, 종료 요건 탭이 열리는지 확인한다. 기존 진행 중인 세이브도 변수 초기화 없이 표시해야 한다.
