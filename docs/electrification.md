# 전기화 (M5)

## 시대관 발생 시점

`tsin_electrification`(`in_game/common/institution/tsin_age_7_institutions.txt`)은 1870년 이전에는 생기지 않는다. 목표(`docs/balance_targets.md`)는 1875~1885년 발생이다.

| 게임 규칙 | 조건 |
|---|---|
| 무작위 도시 | 1870년 이후, 도시·대도시, 그 지점에 산업자본주의 시대관, 소유국이 `tsin_machine_tools_advance`(공작 기계) 연구 |
| 역사적 고정 | 1875년 이후, 베를린 |
| 그럴듯한 곳 | 1870년 이후, `tsin_electrification_plausible_location`(산업자본주의 시대관, 대학, 문해율 > 50, 건물 레벨 > 200, 혁신 값 > 30), 소유국이 공작 기계 연구 |

발생 조건에는 전기화 기술이나 발전소를 쓰지 않는다. 그것들은 전기화 시대관을 받아들여야 열리므로, 조건에 넣으면 영원히 발생하지 않는 순환이 생긴다. 공작 기계는 산업자본주의 기술이라 순환이 없다.

사용자 확인 필요: 관찰 실행에서 발생 연도가 1875~1885년 안에 드는지(`docs/balance_targets.md`). 너무 늦으면 공작 기계 조건을 무작위 도시 규칙에서 먼저 뺀다.
