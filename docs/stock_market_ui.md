# 경제 화면 주식 탭

경제 화면의 공유 탭 묶음 `economy_main_tabs`에 주식을 추가합니다. 새 엔진 lateral view를 등록하지 않고 기존 `economy` 화면에 `subtab = tsin_stocks` 매개변수로 진입합니다. 주식일 때 기존 수지 본문을 숨기고 `tsin_stock_panel`을 표시하며, 수지 탭은 `subtab = balance`로 복귀합니다. 다른 신용·시장·관세·교역 동작은 유지합니다. TSIN 좌하단 관리 창과 현황 버튼은 그대로입니다.

상단은 현재 종합 주가 지수와 기존 `tsin_index_h7`→`h0` 8개 기록의 세로 막대그래프입니다. 모든 막대는 공통 눈금과 0 기준선을 씁니다. 설립 기준가 100 및 기록 중 최댓값으로 눈금 상한을 정합니다. 없는 표본을 0이나 가짜 과거로 채우지 않습니다. 기록은 통상 분기별이지만 거래소 폐쇄 등의 경우 간격이 늘어나므로 실제 날짜 대신 관측 순서를 표시합니다. 현재 지수와 마지막 기록은 분기 사이 충격으로 다를 수 있습니다.

하단은 `gen_company_decisions.COMPANIES`의 강철·기계·직물·화학·철도·농기계 6개 기업 카드입니다. 국가 보정치로 설립 여부를 판정하며 주가는 기존 변수를 읽습니다. 본사는 저장된 위치가 유효할 때 이동할 수 있습니다. `tsin_dashboard_age7_cache_effect`에 기업 관련 건물 레벨 6종과 통계 연도를 추가했습니다. 기존 연간 집계를 사용하고, 탭 첫 클릭 시 버전 2로 일회성 통계 초기화합니다. GUI에서 국가 전체 건물을 매 프레임 순회하지 않습니다. 기업 가치 추정치는 현재 주가 × 기록된 건물 레벨이며 국고나 현실의 시가총액이 아닙니다. 기업 설립·특허장·해산은 기존 결단을 열어 처리하므로 기술·비용·확인 절차를 우회하지 않습니다.

## 파일 및 재생성

- `tools/gen_stock_market_ui.py`: GUI·표시용 스크립트 값·소유 여부 판정·영/한 현지화 생성.
- `in_game/gui/economy_lateralview.gui`: 설치된 바닐라 원본에 진입점과 본문 표시 조건만 추가한 전체 파일 오버라이드.
- `in_game/gui/tsin_stock_market.gui`: 그래프와 기업 카드 공용 타입.
- `in_game/common/scripted_effects/tsin_dashboard_age7_effects.txt`: 연간 건물 통계 및 기존 세이브 마이그레이션.

`python tools/gen_stock_market_ui.py`로 바닐라 기반 6개 파일을 생성하며 `--check`는 비교만 합니다. 게임 업데이트 뒤 원본 구조가 바뀌면 앵커 검사가 중단합니다. 생성된 원본 GUI를 손으로 고치지 말고 생성기에서 변경합니다.

Glorp는 공유 탭을 별도 파일로 분리하므로 두 파일 모두 패치합니다. `--glorp-source <Glorp폴더> --compat-output <호환모드폴더>`를 지정하면 현재 Glorp 원본의 `economy_lateralview.gui`와 `vanilla/cmfg_economy_lateralview_vanilla_types.gui`를 호환 모드에 생성합니다. `--check`와 함께 쓰면 실제 호환 파일까지 확인합니다. 다른 호환 파일은 건드리지 않습니다. 이 두 로컬 파일은 다른 저작자의 원본을 포함하므로 원격 저장소에 넣지 않습니다. 전체 호환 생성기의 Glorp 분기에도 연결했습니다. 로드 순서는 Glorp → TSIN → TSIN Playset Compat이어야 합니다.

## 검증 범위

회귀 검사는 기존 수지 본문의 원형 보존, 수지 복귀, 공유 탭의 진입 경로, Glorp 분리 파일 양쪽 연결, 기존 데이터와 기업 통계 공급 연결을 확인합니다. 표준 통합 검사도 생성 파일과 진입점을 비교합니다. 게임 GUI 엔진은 정적 검사로 실행하지 못하므로 재시작 후 경제 → 주식 진입, 수지 복귀, 그래프 크기, 스크롤, 본사 이동, 결단 이동을 인게임에서 확인해야 합니다. 이력이 없는 국가와 기존 세이브를 모두 확인하세요.
