# 관문 G — 전력 공급 방식

상태: **스크립트 분석으로 방식 결정, 게임 내 동작은 사용자 확인 필요**

## 질문

전력을 무엇으로 표현할 것인가.

- **A. 지역 공급:** 발전소가 지점 변수나 지점 보정치를 주고, 주변 지점에 퍼뜨린다.
- **B. 교역 상품:** 발전소가 상품 `tsin_electricity`를 만들고, 공장 생산 방식이 그것을 투입으로 쓴다.

빅토리아 3에서 전력은 교역되지 않는 지역 상품이다. EU5에는 같은 기능이 없다.

## 바닐라 근거

| 항목 | 내용 | 위치 |
|---|---|---|
| 교역 불가 상품 | 상품 정의에 교역을 끄는 항목이 없다. 거리 비용은 `transport_cost`(기본 1)뿐이다 | `in_game/common/goods/readme.txt` |
| 시장 단위 수급 | 시장 범위 값 `goods_supply_in_market(goods:X)`, `goods_demand_in_market(goods:X)`, `stockpile_in_market(goods:X)` | `trigger_localization/market_triggers.txt`, `generic_actions/columbian_exchange.txt` |
| 투입 부족 | 생산 방식의 투입이 시장에서 모자라면 건물 산출이 줄어드는 것은 바닐라 경제의 기본 동작이다 | 바닐라 공장 전반 |
| 지점 보정치 확산 | 건물 `modifier`는 그 지점에만 붙는다. 이웃 지점으로 퍼뜨리려면 매년 지점을 순회하는 스크립트가 필요하다 | `building_types/readme.txt` |

## 결정: B (교역 상품, 높은 운송비)

| 기준 | A 지역 공급 | B 교역 상품 |
|---|---|---|
| 전력 부족 시 생산 제약 | 직접 만들어야 함(보정치 계산) | 바닐라 투입 부족 처리로 자동 |
| 성능 | 매년 전 지점 순회 필요 | 추가 스크립트 없음 |
| 지도 모드 | 지점 변수 | 시장 수급 값으로 공급·부족·미연결 3색 |
| 빅토리아 3와의 차이 | 지역 단위로 가까움 | 시장 사이 교역이 생김 |

B의 약점(시장 사이 교역)은 `transport_cost`를 크게 잡아 줄인다. EU5 시장은 이미 지역 단위라 "전력망 = 시장"이라는 해석도 자연스럽다.

## 설계

| 요소 | 값 | 위치 |
|---|---|---|
| 상품 `tsin_electricity` | 생산품, 가격 3, `transport_cost` 5, 주민 수요 없음 | `in_game/common/goods/tsin_goods.txt` |
| 생산 | 발전소 `tsin_power_station` (석탄 화력 / 수력 / 석유) | `in_game/common/building_types/tsin_power_buildings.txt` (M5 건물) |
| 소비 | 공장의 전동화 생산 방식, 전기 조명 등 | M5 건물, M5 기술 |
| 지도 모드 | `tsin_electrification`: 시장 공급 ≥ 수요(공급), 공급 < 수요(부족), 둘 다 0(미연결) | M5 지도 모드 |

## 확인 방법

1. 콘솔로 한 나라에 전기화 기술을 주고 발전소 1곳과 전동화 공장 1곳을 짓는다.
2. 시장 화면에서 `tsin_electricity`의 공급·수요가 보이는지 본다.
3. 발전소를 끄거나 없애고, 전동화 공장의 산출이 줄어드는지 본다.
4. 이웃 시장으로 전력이 수출되는지, 수출된다면 양이 작은지 본다(`transport_cost` 효과).

## 미확인 위험

- `transport_cost` 5가 시장 사이 교역을 충분히 막는지.
- 상인이 전력을 다른 시장으로 옮기는 교역로를 AI가 만들 때의 이익 판단.
- 주민 수요가 없는 상품이 시장 화면에 정상적으로 나오는지(모드 상품 `tsin_engines`와 같은 조건이라 문제없을 것으로 추정).
