# 변경 이력

맨 위 항목의 버전은 `.metadata/metadata.json`의 `version`과 같아야 한다(`tools/build_release.py`가 검사). 버전 규칙은 `docs/release.md`.

## 0.7.0 (개발 중) — 산업 사회로의 진입

게임 안 시험 전 빌드다. 모든 기능이 **사용자 확인 필요** 상태다. 세이브 이전 버전(`tsin_version`)은 3이다. 0.7 작업은 이 한 항목에 모았다.

### 시간 압축과 인구
- 제7시대 보정치 강화, 산업 가속 단계 3개, 세계 인구 조절기(게임 규칙 `tsin_population_governor`), 국가 제동과 인구 변천.
- 배출구: 콜레라 대유행 재난, 대이주 상황. 표준시 채택 결단.

### 기술
- 제7시대 기술 트리 확장(시대관 줄기 심화, 무료 트리, 군사·유닛·정부·종교 기술, 해금 기술 정리). 특화 선택지를 모두 열었다.

### 경제와 사회
- 자동화 업그레이드, 채굴 단계, 시장 접근도 상한, 농업 혁명(농기계·질소 고정·기계화 농장, 곡물 침공 상황).
- 노동: 공장 노동자 비중, 노동 조건과 불만, 사회주의 세포, 노동 특권·의제, 씨앗 이벤트.
- 주거(공동 주택·모범 주택), 기반 시설 업그레이드(상수도, 증기 항구, 도청, 도시 조명망), 교육 사다리(공립 중등학교, 연구 대학, 중등·고등교육률).
- 대체 건물 참조: 옛 건물을 묻는 바닐라·모드 조건이 업그레이드 건물도 받는다(`docs/replaced_buildings.md`).

### 입법과 기업
- 확률 입법: 사회 법과 일부 바닐라 법을 법안으로 발의하고, 성공 확률에 따라 통과한다. 논쟁 이벤트와 AI 발의 포함(`docs/legislation.md`).
- 기업: 본사와 주가, 분기 갱신, 주가 이벤트, 특허장 결정, 회장, 증권 보고서, 식민 특허 회사, 트러스트 법과 독점 금지 이벤트(`docs/corporations.md`).
- 경제 통계: 추정 GDP·1인당 GDP·성장률, 연간 로그와 외부 도구 `tools/econ_report.py`, 국가 통계국 개혁, 금본위제 법(`docs/economic_statistics.md`).
- 국가 연구소 정부 개혁(실험 과학 기술 해금), 공중 보건 운동·도시 재개발 내각 행동.

### 역사 콘텐츠
- 상황: 민족 통일, 방어적 근대화(기존 근대화 칙령 흡수).
- 재난: 연방 분열 위기, 천년왕국 대반란.
- 골드러시 이벤트 사슬과 개척지 토지 법, 열강 이벤트(회의·제네바 협약·해군 경쟁)와 이원 제국 결단, 과학·문화 이벤트와 산업 공법 운하 결단, 극후반 씨앗 이벤트(제1인터내셔널, 무정부주의자 암살, 수도의 코뮌).
- 역사 체크포인트(1850·1870·1900)를 관찰 보고서에 넣었다.

### Modern Times 참고 콘텐츠 (워크숍 3792511867, `docs/modern_times_reference.md`)
- 노동 계급 이벤트 7개(조립 라인, 기계에 먹히다, 신경 쇠약, 붉은 깃발, 감옥, 백화점, 떠나는 길).
- 경제·기반 이벤트 5개(궤간, 가스 공장, 석탄 기지, 거품 회사, 은행 인출 사태), 사회 이벤트 5개(대악취, 공원, 야학, 인구 조사, 예방 접종), 발명 이벤트 3개(고무, 내연 기관, 무선).
- 제7시대 제도 3종 발상지 보정치.
- 그림: 건물 11종(자동화 공장 4종, 기계화 방직 공장, 증기 제재소, 발전소, 연구 대학, 도청, 발파 채굴장, 기계 공장), 제도 2종, 7시대 아이콘·삽화, 전기·석유·고무 그림을 Modern Times 그림으로 바꿨다(그 모드가 설치돼 있을 때 `tools/make_placeholder_art.py --from-reference`).

### 인터페이스
- 지도 모드 8종: 자동화, 공업 입지, 기반 시설, 노동 조건, 주거, 1인당 GDP, 기업, 농업.
- 산업화 임무 팩 곁가지 임무 5개(자동화, 주거 개선, 첫 법안, 종합지수, 기계화 농장).
- 백과사전 개념 9개(시간 압축, 인구 조절기, 농업 혁명, 자동화, 노동 조건, 법안, 기업, 종합지수, 추정 GDP), 힌트 3개(노동 불만, 첫 법안, 주가 폭락).

### 개발 도구
- `validate.py`: 참조 검사에 `religion:`, `government_reform:`, `government_type:`, `policy:`, `estate_privilege:`, `culture:` 등과 `has_advance`를 더했다.
- `audit.py`: 건물 검사 추가. 이윤율(산출 가치 ÷ 투입 비용 1.25~1.5), 새 건물의 재화 1종, 기술 단계형 생산 방식.
- `observer_report.py`: 0.7 지표(인구 조절기 지속, 식량 잉여, 법안 수, 종합지수, 1인당 GDP).
- 호환 재스캔 결과는 `docs/compat.md` "0.7 재스캔".

### 밸런스
- 기계 공장 석유 윤활 방식 산출 0.33 → 0.27(이윤율 1.65 → 1.35, 다른 공장과 같게).

### 알려진 제한
- 게임에서 확인하지 않았다. 문서마다 "사용자 확인 필요" 항목이 있다(지도 모드 조건, 임무 개수 조건, 발상지 보정치, 금본위제 법 조건, 관찰 값의 `capital.market` 사슬 등).
- 전기화 제도와 지도 모드 아이콘은 아직 임시 그림이다.

## 0.6.0 (2026-11-14) — 1900 완성판 후보

게임 안 시험 전 빌드다. 모든 기능이 **사용자 확인 필요** 상태다.

### 시대와 제도
- 제7시대 "산업의 시대"(1837). 종료일을 2337년으로 연장했다.
- 제도 3종: 산업자본주의, 대중사회, 전기화(1870년 이후).
- 바닐라 제5·6시대 콘텐츠(제국주의·민족주의 전쟁명분, 혁명, 의회 안건 등)가 제7시대에도 이어지도록 92개 객체를 패치했다.

### 기술과 경제
- 제7시대 기술 74개(시대 선택 발전 30개 포함).
- 새 재화 6종: 기관, 비료, 폭약, 고무, 석유, 전력.
- 새 건물 9종: 기계 공장, 기계화 방직 공장, 비료 공장, 폭약 공장, 철도역, 발전소 등.
- 철도와 시장 접근성, 산업 투자 법, 내각 행동 2종, 산업 기업 결정, 관세 동맹 국제기구.

### 사회와 정치
- 사회 법 6종(노동, 복지, 조세, 집회, 토지 개혁, 교회와 국가), 노예무역 법과 노예제 폐지 압력·해방, 의회 의제·계층 특권·정부 개혁.
- 정치 운동 5종(자유주의, 민족주의, 노동조합, 사회주의, 여성 참정권).

### 상황, 재난, 이벤트
- 상황 4종: 국민의 봄, 장기 불황, 식민지 분할, 만국박람회.
- 재난: 대기근.
- 이벤트 67개: 경제, 발명, 사회, 군사, 예술, 지역 플레이버, 시스템 알림.
- 임무 팩 2종(산업화, 근대화 개혁), 탐험 3종, 조약항 평화 조약.

### 군사와 예술
- 제7시대 유닛 19종과 군사 기술, 군사 이벤트.
- 제7시대 예술 작품 4종.

### 인터페이스와 설정
- 지도 모드 7종: 산업 시대 제도, 산업화, 산업 투자, 도시화, 노동 불안, 급진성, 전력.
- 백과사전 개념 5개, 상황 힌트.
- 게임 규칙: 플레이버 이벤트 빈도, 전기화 시기, 관찰 측정 기록.

### 개발 도구
- 검증(`validate.py`), 배포 점검(`audit.py`), 관찰 실행 보고서(`observer_report.py`), 플레이셋 호환 스캔(`compat_scan.py`), 배포 복사본 생성(`build_release.py`).

### 알려진 제한
- 그림은 바닐라 그림을 다시 칠한 임시 그림이다.
- 다른 모드와 같은 바닐라 객체를 바꾸면 이 모드 쪽이 적용된다(`docs/compat.md`).
- 모드를 켠 세이브에서 모드를 끄면 세이브를 쓸 수 없다(`docs/release.md`).
