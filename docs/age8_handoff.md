# 제8시대 인계 (이념 갈등)

제7시대(1837~1900)는 산업화가 주제이고, 이념 갈등은 제8시대로 넘긴다. 이 문서는 8시대를 만들 때 이어받을 것과 미뤄 둔 것을 적는다. 8시대가 생기기 전까지 여기 적힌 것은 구현하지 않는다.

## 1. 넘겨주는 상태 (8시대가 읽을 값)
| 이름 | 범위 | 종류 | 의미 |
|---|---|---|---|
| `tsin_labor_grievance` | 0~100 | 국가 변수 | 노동 불만. 총파업·혁명 운동의 출발점 |
| `tsin_socialist_cell` | 있음/없음 | 지점 변수 | 1885년 이후 생긴 사회주의 세포. 8시대 정당·봉기의 거점 |
| `tsin_socialist_cells` | 정수 | 국가 변수 | 세포가 있는 지점 수(연간 집계) |
| `tsin_socialism`, `tsin_labor_unionism` | 0~100 | 국가 변수 | 기존 운동 세기 |
| `tsin_secondary_education` | 0~90 | 국가 변수 | 중등교육률. 조직화된 숙련 노동자층 |
| `tsin_higher_education` | 0~60 | 국가 변수 | 고등교육률. 이념 운동의 지도부가 될 지식인층 |
| `tsin_stock_index` | 기준 100 | 국가 변수 | 종합 주가지수. 대공황형 사건의 기준선 |
| `tsin_company_*`, `tsin_charter_*` | 있음/없음 | 국가 변수 | 기업과 특허장. 트러스트·국유화 논쟁 |
| `tsin_gdp`, `tsin_gdp_per_capita` | 실수 | 국가 변수 | 추정 GDP. 총력전 동원 규모의 기준 |
| `tsin_first_international_founded` | 있음/없음 | 전역 변수 | 제1인터내셔널 씨앗 이벤트가 일어났는지 |
| `tsin_commune_uprising_happened` | 있음/없음 | 국가 변수 | 패전 뒤 도시 봉기를 겪었는지 |

## 2. 8시대 백로그 (7시대에는 넣지 않음)
- 마르크스주의를 종교처럼 퍼지는 사상으로 다루는 체계(Modern Times의 마르크스주의 종교 참고). 7시대는 세포 씨앗만 둔다.
- 공산주의 클럽·노동 언론 건물, 몰수·수용 일반 행동, 인민공화국 정부 유형과 전환 결단.
- 총파업, 혁명 재난, 코뮌 체제. 7시대의 코뮌형 사건은 드문 지역 수정자뿐이다.
- 파시즘·민족주의 대중 운동, 국제 연맹형 국가 간 조직체, 총력전.
- 대공황(1929)형 금융 위기: 종합지수와 GDP 기록을 이어받는다.

## 3. 8시대가 생기면 옮길 농업 혁명 후반 기술
제7시대가 마지막 시대라서, 역사적으로 1900년 이후인 기술은 7시대 줄기의 끝에 긴 선행 사슬로 두었다. 8시대가 생기면 옮긴다.
- `tsin_nitrogen_fixation_advance`(질소 고정, 하버-보슈 1909~1913)와 질소 고정 공장 해금.
- `tsin_ammonia_synthesis_advance`(암모니아 합성)와 질소 고정 공장의 암모니아 생산 방식.
- `tsin_intensive_farming_advance`(집약 농업)의 후반 효과.
- 전노급 전함 이후의 노급 전함, 내연 기관 이후의 자동차·항공기는 8시대 몫이다.

## 4. 7시대 콘텐츠가 8시대에 넘기는 연결점
- 노동 불만이 높고 사회주의 세포가 많은 나라는 8시대 시작 시 혁명 운동이 강하게 출발해야 한다.
- 고등교육률이 높은 나라에서 이념 운동이 빨리 생겨야 한다(지식인 지도부).
- 기업 특허장(독점)과 주가지수는 대기업 국유화·반독점 논쟁의 출발점이다.
