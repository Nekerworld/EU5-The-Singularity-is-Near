# 1900년 이후 안정성 (M6)

종료일을 `2337.12.31`로 미뤘으므로(`loading_screen/common/defines/zzz_tsin_defines.txt`) 콘텐츠가 끝난 1900년 뒤에도 게임이 폭주하거나 느려지지 않아야 한다. 목표는 `docs/balance_targets.md` 8절이다.

## 정적 점검 (2026-11-14)

에이전트가 스크립트만 읽고 확인한 내용이다. 게임 안 동작은 아래 "사용자 확인 항목"으로 확인한다.

| 위험 | 확인 내용 | 결론 |
|---|---|---|
| 누적 변수 | 운동 변수 6종은 매년 `clamp_variable`로 0~`tsin_movement_max`에 묶인다. 이벤트가 더하거나 빼도 다음 해 맥동에서 다시 묶인다. `tsin_flavor_events_this_year`는 매년 지운다. `tsin_treaty_ports_opened`는 계속 늘 수 있지만 조건 판정(`> 0`)에만 쓰여 값의 크기가 영향을 주지 않는다 | 폭주 없음 |
| 영구 보정치 | 기간 없는 보정치(`months = -1`)는 모두 `NOT = { has_country_modifier = ... }`로 한 번만 붙거나, 상황·결단·의회 의제가 끝날 때 지운다. 나머지 보정치는 모두 기간이 있고 `add_and_extend`라 겹쳐 쌓이지 않는다 | 폭주 없음 |
| 상황 반복 | 국민의 봄, 장기 불황, 식민지 분할은 전역 변수 `*_happened`로 한 판에 1회다. 각각 3년, 8~20년, 30년 뒤 끝난다. 만국박람회만 1년 개최 뒤 5년 쿨다운으로 반복되도록 설계했다 | 의도대로 |
| 재난 | 대기근은 나라당 1회(`tsin_great_hunger_happened`)이고, 끝 조건의 변수(4년)와 보정치(3년)에 기한이 있다 | 영구 재난 없음 |
| 이벤트 | 발명(7)·예술(3)·군사(3)·지역 플레이버(3) 이벤트는 모두 나라당 1회 변수 조건이 있다. 경제·사회 이벤트는 반복될 수 있지만 전체 빈도를 연간 예산(`tsin_flavor_events_per_year`)이 묶는다 | 늘지 않음 |
| 인구 | 제7시대 `global_population_growth = 0.001`, 시대 첫 기술 0.001. EU5 인구 증가는 식량 잉여와 수용력에 묶이므로(`FOOD_SURPLUS_POP_GROWTH`) 이 값만으로 지수 폭주가 생기지는 않는다 | 관찰 필요 |
| 가격 | 제7시대 `max_price = 6`이 상한이다. `price_stability = 0.02` | 관찰 필요 |
| 군대 | 제7시대 `expected_army_size_modifier = 32`는 고정값이다. 다음 시대가 없으므로 1900년 뒤에 더 커지지 않는다 | 폭주 없음 |
| 성능 | 나라별 맥동, 지도 모드, 상황 순회 비용은 날짜와 무관하다. 1900년 뒤에 새로 켜지는 순회는 없다. 관찰 기록기는 규칙이나 `-debug_mode`일 때만 1년에 한 번 돈다 | 관찰 필요 |
| 시대 | 제7시대가 마지막 시대다. `on_new_age`가 다시 불리지 않고, 다음 시대 기술도 없다 | — |

## 사용자 확인 항목

1. 관찰 실행(`docs/tests/observer_run.md`)을 1950년까지 진행한 뒤 `python tools/observer_report.py`의 "1900년 이후 안정성"이 모두 `[통과]`인지 확인한다. 이 절은 다음을 본다.
   - 세계 인구, 열강 수입, 열강 군대, 강철 가격 비율의 1900→1950 연평균 증가율 5% 이하
   - 1900년 이후 연간 플레이버 이벤트 수가 1880~1899년보다 늘지 않음
2. `python tools/scan_logs.py`에서 1900년 뒤 날짜에 반복되는 오류가 없는지 본다.
3. `docs/perf_baseline.md`의 1900~1910, 1940~1950 구간 속도가 1900년 대비 +20% 이하인지 잰다.
4. 제7시대 기술을 모두 연구한 나라에서 연구 화면이 비어 있어도 오류나 멈춤이 없는지 확인한다. 바닐라 1836년 종료 시점과 같은 상황이지만 그 뒤로 100년 넘게 이어지는 것은 이 모드가 처음이다.
5. 2337년 종료 화면까지는 확인하지 않아도 된다. 1950년까지 안정적이면 같은 구조가 이어진다고 본다.

## 문제가 생기면

| 증상 | 먼저 볼 곳 |
|---|---|
| 인구가 연 5% 넘게 늘어남 | 제7시대와 `tsin_steam_age_advance`의 `global_population_growth`를 0으로, 위생 관련 기술의 수용력 보정치를 절반으로 |
| 한 재화의 가격이 `max_price`에 오래 붙음 | 그 재화의 `goods_demand`와 생산 건물 산출량 |
| 플레이버 이벤트가 1900년 뒤에 늘어남 | 해당 이벤트의 1회 조건 누락 (`tsin_economy.*`처럼 반복 가능한 이벤트의 가중치) |
| 1900년 뒤 속도 저하 | `docs/perf_baseline.md` "판정"의 의심 순서 |
