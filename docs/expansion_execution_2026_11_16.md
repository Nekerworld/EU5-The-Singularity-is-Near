중단 시 외부 work 폴더에만 남아 있던 저장고 초안을 이어서 구현했다. 석유 저장고와 전략자원 비축고는 고용 0이며 단계당 용량 100, 최대 3레벨이다. 유지 투입은 always_add_demands의 도구 0.02/레벨이며 실제 무고용 유지비 결제는 인게임 확인 대상이다. 일반 생산 방식으로 석유·석탄·강철을 생성하지 않는다.

설치된 eu5.exe의 도움말과 바닐라 사건에서 buy_goods_from_market / sell_goods_to_market의 정확한 인자를 확인했다. 매입은 시장 재고를 빼면서 국가 금을 지불하고, 매도는 시장에 재고를 추가하면서 금을 지급한다. 별도 국고 차감·지급을 중복하지 않는다. 등록한 정부 관리 거점만 월 1회 처리하며 AI 자동 설정은 초기 시제품에서 비활성이다. 건물 건설 뒤 TSIN 경제·산업의 설정 버튼으로 석유/석탄/강철 하나를 선택한다.

기준가 85% 이하에서 매입 시작·95%까지 지속, 115% 이상에서 매도 시작·105%까지 지속한다. 월 입출고 상한 10, 매입은 남은 용량·시장 실재고·조회 가격 기준 국고 5% 이내로 제한한다. 실제 거래가격/정산액은 엔진이 결정하므로 5%는 사전 추정 예산이다. 평시 용량의 25%를 남기고 비상 예약은 다음 월 1회 하한을 무시한다. 자동 정지·재개·선택 저장고 수동 조사 버튼을 연결했다.

재고가 남은 동안 재화 종류를 바꾸거나 수량을 0으로 재설정하지 않는다. 실행 직전에도 소유권·통제·보유량을 재검사한다. 저장량은 지점 귀속으로 소유국·시장 변경에 복사하지 않는다. 입고량은 실제 시장 감소량으로 기록하고 출고 요청량은 실행 전에 차감해 중복 매도를 막는다. 관측 수량이 요청과 0.01 넘게 다르면 요청·관측값을 남기고 상태 99로 정지한다. 실패 상태를 자동 복구하거나 재고를 임의 환원하지 않는다. 이미 체결된 네이티브 거래를 원자적으로 되돌린다고 주장하지 않는다. 철거 후 잔량은 장부에 보존되며 신규 매입은 용량 0으로 중단된다.

중요 인게임 검증: 매입/매도 직후 stockpile 조회가 즉시 갱신되는지, 실제 수량/국고/유지 투입의 일치, 0재고 방출 금지, 가격 히스테리시스, 시장/소유권 변경, 철거 후 잔량. 이 검증 전에는 대규모 운용이 검증되었다고 볼 수 없다. 저장고 전용 3개 검사 통과. 정적 검사에서 인라인 생산 방식 정의 인식 문제가 나와 다중행 블록으로 정리한 뒤 재검사했다.

## 국제 표준화 논의 — 단계 6b

고정 연도가 아닌 산업국 3개 이상을 기준으로 개최한다. 국가의 공장 비중 5%·중등교육 10%·수도 시장 접근 50%를 연 1회 전역 검사하며, 주최국은 공학 교육·공장 비중 10%·중등교육 20%·평화·500두캇이 필요하다. AI는 충분한 현금과 연간 검토로 제한한다. 회의는 3년, 이후 세계 재개최 간격은 25년이다.

도량형·철도 규격·산업 부품·전기 설비의 4개 선택 변수를 분리했다. 공통·병용/환적/변환·독자 규격을 선택하며 산업 부품은 공통/국내 2가지다. 선택별 실제 비용과 5년 재선택 간격이 있다. 독자 규격의 유지는 다른 분야 협약 가입을 막지 않는다. 공통 선택의 무역 용량·철도 건설비·연구·전기 설비 생산 보정은 제한된 게임 추상화다. 모든 선로를 개궤하거나 네이티브 운행을 금지하지 않고 독립 송전망을 만들었다고 표시하지 않는다.

폐회 때 적어도 한 분야에서 실제 공통 규격 채택국이 2개 이상이어야 협약 성립이다. 독자 규격을 선택한 2개국이 단순 참석만으로 합의한 것으로 집계되지 않는다. 국가가 소멸한 경우를 포함해 생존국 기준으로 연간 재검사한다. 기존 채택국의 선택은 폐회 후 보존하고 협약 성립 후 후발국 가입도 허용한다.

상황 전용 패널에 모든 실제 선택 버튼과 현재 선택 값을 연결했다. TSIN 과학기술 탭에도 개최/선택 진입을 제공한다. 그림은 기존 세계박람회 자산을 임시 재사용한다. 전용 회귀 3개 통과, 정적 검사 오류 0·경고 0. 실제 상황 개시·주요 행동/패널 표시·AI 개최·선택 비용·합의/불성립 폐회는 인게임 검증 대기다.
