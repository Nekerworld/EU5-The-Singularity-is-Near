## 세계 기업 통계 창 — 단계 4c

조사 결과는 단조 증가 행 ID의 전역 맵과 조사국 자체 행 목록에 보관한다. 다른 플레이어의 행을 덮어쓰지 않으며 재조사는 자기 이전 행만 제거한다. 필터·정렬·페이지는 이 스냅샷만 처리하고 국가·지점·기업 실물을 재조사하지 않는다. 창 열기·호버·닫기는 게임 집계를 실행하지 않는다. 별도 정기 콜백이나 AI 자동 조사를 추가하지 않았다.

## 입법 현황 카드 — 단계 7b

기존 법안을 읽는 독립 우측 카드를 scripted_widgets에 등록했다. Glorp·바닐라 아웃라이너 파일과 건설·군대 목록을 덮어쓰지 않는다. 기본 위치는 우측 목록 왼쪽이며 이동·접기·닫기·TSIN 위기·정책에서 다시 열기를 지원한다. 접으면 실제 창 크기도 68로 줄이고 펼치면 380으로 늘려 빈 투명 영역을 남기지 않도록 했다.

법안 정책명, 성공/정체 수, 다음 한 번의 심의 성공 확률, 계층별 지지/반대·영향력, 법률 화면 진입을 제공한다. 성공 확률을 최종 통과 확률로 표시하지 않는다. 카드 열기·호버·접기에는 판정 효과가 없다.

기존 두 3개월 타이머 설정 지점에 대기 종료 연월 메타데이터만 추가하고 법안 정리 시 함께 지운다. eu5.exe 도움말로 current_month가 1~12임을 확인했으며 연말 이월을 처리한다. 실제 심의는 기존 타이머 종료 후 원래 월간 심의 경로가 결정한다. 따라서 카드는 정확한 심의일 대신 대기 종료 연월이라고 표시한다. 이전 법안은 날짜 자료 없음을 표시하고 타이머를 재설정하지 않는다.

## 환경법·수질 처리·광산 조사 — 단계 6d

## 도시 권한 호환 보완

8시대 자동차 물류 기지·비행장처럼 city/megalopolis 권한을 한 줄에 작성한 정의가 기존 줄 시작 정규식에 잡히지 않았다. 최상위 스칼라 필드를 읽도록 바꾸어 중첩 조건·문자열을 권한으로 오인하지 않으며, 주입·명시적 no·copy_from 상속을 반영한다. 명시적인 새 등급 허용/금지는 보존하고 기존 권한도 정의된 경우만 대응시켜 미정 기본값을 임의로 금지하지 않는다.

동일 경로는 플레이세트 순서로 고르고 살아남은 파일을 전체 파일명 순으로 읽는다. TSIN을 활성 순서와 무관하게 마지막에 재적용하던 가정도 제거했다. 현재 활성 플레이세트에서 우리 권한 패치보다 뒤에 읽히는 건물 파일은 0개로 확인했다. 타 모드 전체 정의는 복제하지 않고 권한만 TRY_INJECT한다.

은행 감독법 4정책과 기업 공개법 2정책을 기존 법률·입법 메뉴에 연결했다. 기본/정책 미설정은 기존 신규 대출 준비 비율 20%이며 자유 은행10%, 건전성30%, 엄격40%로 구분한다. 건전성·엄격 감독은 신규 대출에 은행 감사를 요구하고 의무 공시는 신규 기업 대출·회사채·증자에 기업 감사를 요구한다. 해외 신용의 대주는 은행 감독, 차주는 공시 요건을 검사한다. 기존 계약의 이자·원금·예금 인출·정리·손실 조정은 새 기술/감사로 차단하지 않는다. 정리 중인 은행의 신규 대출도 차단했다.
