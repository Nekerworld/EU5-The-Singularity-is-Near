# 제8~12시대 뼈대 — 2026-11-15

등록된 ID와 시작 연도:

| 시대 | ID | 시작 |
|---|---|---|
| 7 산업 | age_7_industrialization | 1837 |
| 8 대전 | age_8_world_wars | 1900 |
| 9 원자력 | age_9_atomic | 1945 |
| 10 정보화 | age_10_information | 1990 |
| 11 인공지능 | age_11_artificial_intelligence | 2035 |
| 12 우주 개척 | age_12_space | 2120 |

`data/eras.json`이 연표 원본이다. `python -B tools/gen_era_skeleton.py`가 후속 시대 정의·후기 시대 트리거·영한 현지화·임시 그림을 생성하고, `--check`는 파일을 수정하지 않고 재현성을 검사한다. 7시대 정의는 수정하지 않는다. 후속 시대는 한 파일에 8→12 순서로 정의하며 7시대 파일 뒤에 읽히는 이름을 사용한다.

새 기술·시대관·이벤트·상황·상품·건물·새 밸런스는 추가하지 않았다. 시대가 바뀔 때 경제 기본값이 0으로 돌아가는 것을 피하려고 7시대 기본 규칙을 그대로 복사한다. 이는 후속 시대 전용 밸런스가 아니다. 아이콘과 발전 배경은 7시대 DDS를 변경 없이 복사한 임시 자산이다.

5·6·7시대의 current_age_or_later 연결을 12시대까지 확장하고, 8~12시대용 같은 형태의 트리거도 등록했다. 7시대에 처음 진입할 때만 실행하는 기존 초기화 조건은 유지한다. 기존 age=7 기술을 age=8로 복제하거나 연구를 지급하지 않는다. 후속 시대의 기술 화면은 전용 콘텐츠가 없어 비어 있을 수 있다.

2200년은 성간문명 개발의 목표 시점이다. 이후 새 시대를 생성하지 않으며 END_DATE=2337.12.31도 변경하지 않는다. 현재는 연도 기준 시대 정의만 등록했다. 보급도에 따른 동적 시대 전환은 향후 구현한다.

검증 범위: 시대 ID·연도 순서·기본값 유지·후기 트리거 포함 관계·현지화/그림 존재·생성물 재현성. 실제 자연 전환, 시대 선택/발전 UI의 12시대 표시, 빈 발전 트리, 저장/재로드는 게임 재실행 후 확인해야 한다. 원본의 모든 명시적인 6/7시대 switch와 birth_age 패치를 12시대용으로 재설계한 것은 아니며, 이 단계에서 후속 시대의 전체 콘텐츠 호환을 보증하지 않는다.

예시 콘솔 전환: `change_age age_8_world_wars`, `change_age age_12_space`. 연도와 무관한 강제 전환은 자연 전환 시험을 대체하지 않는다.
