# 금융 장부 1차 구현

F2는 경제를 유지한다. 내부 금융의 현황·증시·신용에 통화·은행·기금을 연결했다. 기본 UI와 로컬 Glorp 호환 UI를 같은 생성기로 만든다.

## 실제 자금 흐름

- 준비금·은행·보험·연금 출연: 국고 차감 → 해당 장부 증가. 준비금 인출은 반대 거래다.
- 기업 대출: 은행 현금 감소 → 기업 현금 증가, 기업 원금채무와 은행 대출자산 동시 증가. 상환은 가용 현금과 잔여 원금 중 작은 값이다.
- 이자: TSIN 기업 채무 × 연 금리 ÷ 1200. 기업 현금까지만 은행에 지급한다. 기존 국가 대출에는 추가 이자를 붙이지 않는다. 부족한 이자를 새 원금으로 자본화하지 않는다.
- 배당: 기업 채무가 없을 때 가용 현금을 시민 계층에 지급한다. 주가·GDP 추정값에서 현금을 만들지 않는다.
- 적립 연금: 출연된 기금에서 농민 계층에 매월 지급하며 고령 인구에 대한 정밀 모형은 아니다.
- 보험: 이자 부족 6개월 이후 적립기금 25%와 거래 단위 중 작은 금액을 해당 연체기에 한 번 지급한다. 정상 이자 지급으로 회복해야 다음 연체기 청구가 가능하다.

통화 환산은 E=기준 두캇당 자국 단위, 표시 국고=두캇 국고×E다. 평가절하·10:1 화폐개혁은 E만 변경하며 실제 자산을 늘리지 않는다. 현재는 준비 현금이며 실물 금 상품·국제 외환시장과 같은 것으로 표시하지 않는다. 금리는 TSIN 기업 신용창구에만 적용된다.

## 실행·성능·검증

월간 국별 처리이고 지점·팝 반복은 없다. 기존 세이브에 초기 재산을 지급하지 않고 빠진 변수만 0으로 초기화한다. UI 렌더링은 장부를 변경하지 않는다. 각 명령은 실행 직전 지급 조건을 재검사한다.

59개 회귀 검사 통과. 추가 7개 검사는 생성된 수치 구문을 실행하여 현금 보존, 원금/이자, 부족 자금 거부, 화폐개혁, 연금 소진과 보험 중복 청구를 검증한다. 인게임 검증은 전체 개발 종료 후 진행한다.

해외 투자·실물 금 태환·통화동맹·외화 부채·은행 지급불능 청산·실제 공장별 손익은 별도 후속 구현이다. 이 장부만으로 구현되었다고 간주하지 않는다.

## 해외 신용·예금·유동성 확장

은행 영업을 별도로 개시하면 시민 계층 현금을 실제 차감해 예금을 받고 같은 금액을 은행 채무로 기록한다. 기존 예금 잔액의 20%를 남겨야 신규 대출을 실행할 수 있으며 순자산이 음수이면 신규 대출·예금을 막는다. 영업 종료는 신규 예금을 막고 잔액 전액의 인출을 처리한다. 자금 부족 시 미지급 인출은 다음 분기로 이월된다.

국고 출자와 별개로 준비 현금에서 유동성을 빌려줄 수 있지만 은행 채무가 생기며 상환은 반대 거래다. 장부 손실을 현금 지급으로 메우지 않는다. 원금 부실 조정은 자산과 기업 채무를 함께 줄이며 상각 손실을 기록한다. 4회 분기 이상 인출 미지급/순자산 부족이면 건설·생산에 신용 위축 효과가 생기고 회복하면 제거한다.

해외 기업 신용은 국가당 동시 한 건, 독립 AI와 계약하며 지급 시 상대 기업 현금을 증가시킨다. 원금은 차입국 단위로 기록한다. 표시 환율이 바뀌면 기준 두캇 채권 가치가 바뀌고 현금은 지급 때만 이동한다. 분기 1% 고정 이자는 기존 국가 대출과 별개 계약이다. 4분기 후 가용 기업 현금에서 원금을 회수하며, 12분기 이자 불이행 시 상대 채무와 대출자 자산을 함께 상각한다. 차입국 소멸 시에도 대출자 손실이며 무상 국고 지급은 없다.

금본위 정책에서 평가절하하려면 먼저 태환을 5년간 정지해야 하며 위신 10을 소모한다. 기존 금 정책/국가 대출 엔진을 교체하지 않는다. 통화 이름은 국별 표시이며 시작 환산율은 모두 정규화한 1이다. 실제 역사 환율을 재현한 값으로 해석하지 않는다. 은행 화면은 네이티브 스크롤 컨트롤을 사용한다.

AI는 1600년 이후 기업 기반이 있고 국고가 출자 단위의 5배 이상일 때만 실제 자금을 출자한다. 부실 은행 재출자 역시 같은 재정 조건과 실제 차감이 필요하다. 은행의 유동성 위축은 기존 생산/건설을 통해 경제에 반영되며 기존 세계 대공황의 실물 스트레스 조건을 연도만으로 우회하지 않는다.

회귀 검사 72개 통과. 해외 투자 지분 소유·실제 금 상품 태환·통화동맹·고령 인구별 연금은 이 신용/기금 모형과 별도 범위다.
