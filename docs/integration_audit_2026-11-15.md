# TSIN 연결 오류 전수 검증 — 2026-11-15

## 결론

콜레라와 동일한 전용 GUI 누락을 대기근·천년왕국 반란·분리 위기에서 추가로 발견했다. 세 재앙의 패널을 추가했다. 지도 모드 16개는 앞서 수정한 표시 그룹이 기본 UI와 현재 Good Interface에서 모두 유효하다. 새 상황 8개는 패널이 모두 있다.

기존 검증기에는 정의된 기능이 UI에 실제 연결되는지 확인하는 검사가 없었다. 이번에는 이 검사를 기본 validate.py에 편입했다. 구문·참조 검사가 통과해도 실제 게임 검증을 대체하지 못한다.

## 수정한 항목

| 항목 | 문제 | 수정 |
|---|---|---|
| 대기근 tsin_great_hunger | 재앙 데이터는 있지만 동명의 GUI 없음 | 기본 disaster_panel 기반 화면과 종료 요건·대책 안내 추가 |

새 화면은 기본 재앙 템플릿의 월간 효과·행동 목록을 상속한다. 기존에 정의된 행동이 없으면 행동 버튼이 추가되는 것은 아니다. 별도 무료 구호·진압 버튼을 새로 만들거나 재앙의 발생·피해·종료 규칙을 바꾸지 않았다. 각각의 종료 요건은 실제 can_end에서 표시한다.

## 검증기 보강 결과

- 수정 전 새 연결 검사는 재앙 패널 누락 3건을 정확히 검출했다.
- 수정 후 새 연결 검사는 0건이다.
- 보강된 전체 validate.py도 오류 0건·경고 0건으로 통과했다.
- 회귀 검사는 누락 패널, 보이지 않는 index=93, 누락 콜백, 잘못된 대괄호 라벨을 고의로 주입해 검출함을 확인했다. 정상 패널과 index=1에서는 오류가 사라진다.
- release audit는 오류 0건, 경고 2건이다. 하나는 고유 제목 The Singularity is Near의 영한 동일 표기, 다른 하나는 예산과 조건으로 제한된 tsin_economy.70의 any_country 검사다. 두 경고를 새로운 기능 오류라고 확정할 근거는 없다.

기본 실행:

```powershell
python -B tools/validate.py
python -B tools/audit.py
python -B tools/tests/test_integration_checks.py
```

## 추가로 확인된 미해결 문제

### 경제 통계의 외부 로그에 빈 값 출력

보존된 debug.log에는 tsin_economy_log_line 평가 시 ROOT.ScriptValue가 nullptr라는 오류와 다음과 같은 빈 기록이 있다.

```text
TSIN_ECON;name=;year=;gdp=;gdp_pc=;growth=;pop=;index=;grievance=;sec=;high=;fac=;lit=
```

현재 tsin_economy_log_effects.txt와 숨은 이벤트 tsin_system.31은 같은 로컬라이제이션 키를 debug_log에 넘기므로 코드상 관련 경로가 남아 있다. 따라서 econ_report.py의 외부 시계열은 정상 기록이라고 볼 수 없다. 이 사실만으로 게임 내 GDP나 교육 변수의 계산이 실패한다고 볼 수는 없다.

debug_log가 전달하는 로컬라이제이션 범위에 문제가 있다. 저장된 이름 있는 범위 또는 다른 기록 효과가 실제로 지원되는지 게임 내 소규모 실험이 필요하다. 검증하지 않은 새 출력 구문으로 대체하거나 통계 기능을 임의 삭제하지 않았다. 관찰자 기록도 비슷한 ROOT 기반 형식이므로 별도 검증 대상이다.

### 다른 모드의 이란 공백기 오류

보존된 로그에는 LOT strongest_state 변수 및 involved_states 맵 오류가 남아 있다. 로그의 실행 시작은 11월 14일 22:48로 이번 수정 전이다. 따라서 현재 파일을 재시작한 후에도 같은 오류가 발생한다고 판정할 수 없다. TSIN의 새 재앙 화면 누락과는 별개다. 이번에는 LOT의 국가/상황 상태를 추측으로 복구하지 않았다.

## 실제 게임에서 남은 확인

1. 세 재앙의 화면이 열리고 월간 효과·종료 요건·안내가 표시되는지.
2. 기존 진행 중인 재앙을 담은 세이브에서도 별도 초기화 없이 표시되는지.
3. 지도 모드의 표시뿐 아니라 색·툴팁·월간 갱신이 실제 값과 맞는지.
4. 기술 트리의 폭과 선행선 배치가 실제로 개선됐는지.
5. 경제 통계 로그의 범위 문제를 별도 실험으로 해결할 수 있는지.

현재 실행 중인 게임을 강제로 종료하거나 세이브를 변경하지 않았다. 변경은 재실행 후 검증해야 한다. 사용자에게서 받은 '나머지 현재 정상' 보고는 유용한 플레이 관측이며, 모든 경계 조건과 장기 진행 실험을 수행했다는 뜻으로 확대하지 않았다.
