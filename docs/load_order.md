# 로드 순서 지침

## defines (`NGame.END_DATE`)

- 이 모드는 `loading_screen/common/defines/zzz_tsin_defines.txt`에서 `NGame.END_DATE = "2337.12.31"` 하나만 바꾼다.
- 창작마당 3631410954 "EU5 National Ideas"는 `00_defines.txt` 전체를 덮어쓰며, 그 안의 `END_DATE`는 바닐라와 같은 `"1836.12.31"`이다.
- 같은 경로의 파일은 나중에 로드된 모드가 통째로 이긴다. 경로가 다른 defines 파일들은 모두 읽히며, 같은 키는 나중에 읽힌 값이 남는다.
- 근거: 창작마당 모드 다수가 `zz_`, `zzz_` 같은 접두어를 붙인 부분 defines 파일(예: `zzz_REAI_defines.txt`, `z_ai_balance_defines.txt`)을 쓴다. 파일 이름의 알파벳 순서로 덮어쓰기 순서를 정한다는 관행이다.
- 따라서 `zzz_tsin_defines.txt`는 `00_defines.txt`보다 늘 뒤에 읽혀, 모드 목록 순서와 관계없이 이 모드의 종료일이 적용될 것으로 본다. **사용자 확인 필요**: 3631410954를 이 모드보다 아래에 두고 새 게임을 시작해 1837년 이후에도 게임이 끝나지 않는지 확인한다.
- 다른 모드가 `zzz_tsin_`보다 뒤에 정렬되는 파일에서 `END_DATE`를 다시 설정하면 그 값이 이긴다. 2026-11 기준 설치된 창작마당 121개 중 `END_DATE`를 설정하는 모드는 3631410954 하나뿐이다.

## `metadata.json` relationships

설치된 창작마당 모드 중 `relationships`를 실제로 채운 예가 없어, 형식과 동작을 확인할 수 없다. 추측으로 채우지 않고 빈 배열로 둔다. 런처에서 형식이 확인되면 3631410954에 대해 "이 모드 뒤에 로드" 관계를 추가한다.

## 객체 덮어쓰기(`TRY_REPLACE:`, `REPLACE:`)

- 같은 객체를 다른 모드도 덮어쓰면 모드 목록에서 나중에 로드된 쪽이 이긴다.
- 이 모드의 제7시대 연장 패치(`zzz_tsin_age7_*.txt`)가 지면 해당 기능은 제7시대에 바닐라처럼 제6시대 조건으로 남는다. 시대 확인이 빠져 게임이 깨지지는 않는다.
- 충돌 목록은 `docs/overrides.md`에 있다(3827499481, 3604169106이 같은 객체를 건드림).
