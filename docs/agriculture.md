# 농업 혁명 (0.7)

상태: **스크립트 작성 완료, 수확량·인구 증가 수치는 사용자 확인 필요**

7시대 후반의 농업 혁명은 식량 잉여를 늘리고, 바닐라 인구 증가 규칙을 통해 인구 폭증으로 이어진다. 폭증의 상한은 세계 인구 조절기와 국가 제동이 맡는다([tempo.md](tempo.md)).

## 인구 연결 (정적 확인)

- 바닐라 `loading_screen/common/defines/00_defines.txt`의 `NPop`:
  - `FOOD_SURPLUS_POP_GROWTH = 0.0015`: 지방 식량 잉여 1점당 인구 증가.
  - `FOOD_STORAGE_POP_GROWTH = 0.001`: 저장 식량 1점당 인구 증가.
- 그래서 월간 식량 보정치(`local_/global_monthly_food_modifier`)와 식량 용량(`global_food_capacity_modifier`)이 곧 인구 증가 보정이 된다. 모드는 이 define을 바꾸지 않는다.
- 식량 부패 `global_food_decay`는 바닐라 국가 기본값이 0.005이다(`auto_modifiers/country.txt`). 통조림 −0.002, 냉동 운송 −0.001로 합계 60%를 줄인다.

## 건물 (1건물 1재화, 기술 단계형)

| 건물 | 종류 | 내용 |
|---|---|---|
| `tsin_farm_machinery_works` 농기계 공장 | 신규 칸(공장) | 농기계만 생산. 철제(투입 8.88 → 2.4) → 강철(11.11 → 3.0) → 증기 견인(13.32 → 3.6). 이윤율 1.35 |
| `tsin_mechanized_farm` 기계화 농장 | `tsin_fertilized_fields` 개축 | 최대 레벨 1 → 2 → 3(`tsin_mechanized_farm_max_level`). 레벨당 원자재 산출 +20%, 월간 식량 +5%, 유지비 비료 0.15·농기계 0.05·도구 0.01(0.655). 고용 0.15 |
| `tsin_nitrogen_fixation_plant` 질소 고정 공장 | `tsin_fertilizer_plant` 개축 | 비료만 생산. 석회질소법(석탄·전력·석재 16.67 → 9) → 암모니아 합성(18.5 → 10). 고용 0.15 |

- 새 재화 `tsin_farm_machinery`(농기계): 가격 5, 운송비 1, 인구 수요 없음. 기계화 농장의 유지비로만 쓴다.
- 3레벨 기계화 농장은 원자재 +60%로 시비 농지(+15%)의 4배이다. 단, 건물 보정치가 레벨마다 쌓인다는 전제이다(사용자 확인 필요).

## 상황 "곡물 침공" `tsin_grain_invasion`

- 시작: 1873년 이후, 3개국 이상이 증기 상선대 기술을 가졌을 때. 한 판에 한 번.
- 대상: 철도망 기술이 있고 공장 노동자 비중이 20% 미만인 나라. `tsin_grain_invasion_crisis`(식량 +5%, 밀 −10%, 농민·귀족 만족 −, 이주 +10%)를 받는다.
- 매달 낮은 확률(1000분의 4)로 농업 문제 이벤트 `.81`이 온다. 장기 불황 중이면 두 배이다. 선택하면 위기가 끝난다.
  - 곡물 관세: 중상주의 쪽 사회 가치, 귀족 +, 도시민 −.
  - 값싼 빵: 자유무역 쪽, 도시민 +, 농민 −, 승급 속도 +.
  - 농장 근대화(증기 탈곡 필요, 금화): 원자재 +5%, 농기계 생산 +10%.
- 끝: 5년 뒤 위기 국가가 없으면 "새로운 균형", 아니면 15년 뒤 자동 종료.
- 대이주 상황(H절)이 위기 보정치를 이주 압력 조건으로 읽을 예정이다.
